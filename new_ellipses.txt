# Density Algorithm Differences: Analytical vs Monte Carlo

This document explains the differences observed between the analytical PDF implementation (`density_analytical.py`) and the original Monte Carlo implementation (`density.py`).

## Executive Summary

The analytical and Monte Carlo approaches produce **correlated but distinct** density outputs. This is expected behavior due to fundamental algorithmic differences, not a bug.

| Metric | Value | Interpretation |
|--------|-------|----------------|
| Pearson correlation | 0.33-0.36 | Moderate positive correlation |
| Jaccard @ 50th percentile | 43% | Good overall pattern agreement |
| Jaccard @ 95th percentile | 3.5% | Poor extreme-hotspot agreement |

**Key finding:** The algorithms agree on general density patterns but disagree on where the most extreme peaks are located.

---

## Analysis Details

### Test Configuration

- **Dataset:** 20,000 ellipses from `test_data/test_data.csv`
- **Location:** Macon, Georgia area (~32.83°N, -83.6°W)
- **Reference:** Monte Carlo output with `random_seed=42`

### Comparison Results

#### With Precision Weighting (Analytical Default)

| Configuration | Pearson r | Jaccard @ 95% |
|--------------|-----------|---------------|
| cells_across=6 | 0.076 | 0.036 |
| cells_across=10 | 0.066 | 0.034 |

#### Without Precision Weighting (Equal Weight Mode)

| Configuration | Pearson r | Jaccard @ 95% |
|--------------|-----------|---------------|
| cells_across=6 | **0.357** | 0.035 |
| cells_across=10 | **0.334** | 0.035 |

**Disabling precision weighting improved Pearson correlation by ~5x**, confirming that weighting differences were a major factor.

#### Jaccard at Different Thresholds

| Percentile | Jaccard Index | Interpretation |
|------------|---------------|----------------|
| 50th | 0.43 | 43% overlap in "above median" cells |
| 75th | 0.18 | 18% overlap in top quartile |
| 90th | 0.07 | 7% overlap in top 10% |
| 95th | 0.035 | 3.5% overlap in top 5% |
| 99th | 0.005 | 0.5% overlap in top 1% |

---

## Root Causes

### 1. Density Estimation Method

| Aspect | Monte Carlo | Analytical PDF |
|--------|-------------|----------------|
| Method | Random point sampling | Exact Gaussian PDF evaluation |
| Randomness | High (stochastic) | None (deterministic) |
| Noise | Present (sampling artifacts) | Absent (mathematically smooth) |

Monte Carlo randomly scatters points within each ellipse and counts how many land in each grid cell. This introduces noise—where multiple random points happen to land in the same cell by chance, you get a spurious "peak."

Analytical PDF evaluates the exact 2D Gaussian probability density at each grid cell center. Peaks occur only where the mathematics dictates highest probability.

### 2. Weighting Scheme

| Approach | Weighting | Effect |
|----------|-----------|--------|
| Monte Carlo | Equal weight per ellipse | Large ellipses contribute equally to small ones |
| Analytical (default) | Precision × confidence | Small, precise ellipses dominate the output |
| Analytical (equal mode) | Equal weight | Matches Monte Carlo weighting philosophy |

The precision weighting (`weight = 1/√det`) causes small ellipses to have disproportionately high influence in the analytical output, shifting hotspots to areas with many small ellipses.

### 3. Peak Structure Differences

| Metric | Monte Carlo | Analytical |
|--------|-------------|------------|
| Hotspot regions (95th pct) | 3,582 | 2,916 |
| Mean region size | 4.2 cells | 2.6 cells |
| Peak count | More, larger | Fewer, smaller |

Monte Carlo produces more numerous, larger hotspot regions due to random clustering. Analytical produces fewer, more focused peaks at mathematically optimal locations.

---

## Grid Specification Differences

The implementations use different cell size calculations:

### Monte Carlo (`density.py`)
```
cell_size = mean([min, 25th_percentile of semi_major]) × 0.2
         → clamped to MIN_CELLSIZE (0.0001°, ~11.1m)
```

### Analytical (`density_analytical.py`)
```
cell_size = (2 × reference_semi_minor) / cells_across
```

Where `reference_semi_minor` depends on `cell_size_basis`:
- `"avg"`: mean of all semi_minor values
- `"p10"`: 10th percentile of semi_minor values

**Note:** Matching grid resolution (tested with `cells_across=13` for ~11m cells) did not improve Jaccard, confirming that grid differences are not the primary cause.

---

## Recommendations

### For Users Migrating from Monte Carlo

1. **Use equal weighting mode** (`use_precision_weighting=False`) for closest match to Monte Carlo behavior

2. **Focus on Pearson correlation** rather than extreme-hotspot Jaccard when comparing outputs

3. **Accept some hotspot differences** as inherent to the algorithmic change—analytical hotspots are mathematically "more correct"

### For New Projects

1. **Use analytical with precision weighting** (default) for mathematically rigorous density estimation

2. **Use analytical with equal weighting** if you need output comparable to existing Monte Carlo pipelines

3. **Consider the use case:**
   - Precision weighting: Better for identifying locations with many high-confidence observations
   - Equal weighting: Better for raw observation density regardless of precision

---

## Technical Notes

### Why Jaccard Drops at Higher Percentiles

Jaccard index measures set overlap: `intersection / union`. At higher percentiles:
- Fewer cells qualify as "hotspots"
- Small spatial shifts have larger relative impact
- Random noise in Monte Carlo creates non-reproducible peak locations

A Jaccard of 0.43 at 50th percentile but 0.035 at 95th percentile is consistent with:
- Good overall pattern agreement
- Poor agreement on exact peak locations
- Monte Carlo noise creating spurious extreme peaks

### Spatial Alignment Testing

Shifting the analytical grid by ±5 pixels in each direction produced negligible Jaccard improvement (0.0347 → 0.0360), confirming that grid misalignment is not a significant factor.

## Accuracy Analysis: Peak Location vs Known Cluster Centers

Testing with synthetic data containing a known cluster center allows measuring **accuracy** (distance from true center) in addition to **precision** (agreement between algorithms).

### Test Setup

- **Dataset:** 20,000 ellipses with 1 cluster center (80% clustered, 20% random)
- **Cluster position:** Centered in bounding box (46% lat, 37% lon)
- **Cluster spread:** 10% of bounding box extent (Gaussian std)

### Accuracy Results

| Method | Error from True Center | Cell Size | Error in Cells |
|--------|----------------------|-----------|----------------|
| Simple Grid Count | **64.5 m** | ~38 m | 1.7 |
| Analytical (cells_across=10) | **240.1 m** | ~14 m | 17.1 |
| Monte Carlo | **516.9 m** | ~11 m | 47.0 |

**Precision (agreement between MC and Analytical):** 416.1 m

### Cell Size Impact on Accuracy

| Configuration | Cell Size | Error (m) | Notes |
|--------------|-----------|-----------|-------|
| cells_across=6 | 23.4 m | 827.1 m | Too coarse |
| cells_across=10 | 14.0 m | **240.1 m** | **Optimal** |
| cells_across=15 | 11.0 m | 1303.5 m | Floored at MIN_CELLSIZE |
| cells_across=20 | 11.0 m | 1303.5 m | Floored at MIN_CELLSIZE |

**Key finding:** The default `cells_across=10` (~14m cells) provides optimal accuracy. Smaller cells (11m floor) actually **decrease** accuracy due to increased sensitivity to local variations in the precision-weighted density.

### Why Density Algorithms Differ from Simple Point Counting

Simple grid counting finds the cell with the most ellipse **centers**, achieving the best accuracy to the generation center (64.5m).

Density algorithms compute **ellipse overlap probability**, which:
- Weights by ellipse size and confidence (analytical) or sample distribution (Monte Carlo)
- Finds where probability mass is highest, not just where centers cluster
- Can shift peaks away from the center of mass when ellipse properties vary spatially

This is **correct behavior** for location uncertainty modeling—the algorithms find where the actual probability is highest given the ellipse geometries, not just where points were generated from.

### Edge Effects

When cluster centers are placed near bounding box edges, accuracy degrades significantly:

| Cluster Position | Algorithm Error |
|-----------------|-----------------|
| 2.5% from edge | ~850-930 m |
| 37-46% (centered) | ~240-517 m |

Clusters near edges experience truncation (~40% of points clamped to boundary), artificially shifting the density peak. Always ensure cluster centers have adequate margin from bounding box edges when generating test data.

## Cell Size Correlation Study

An automated study investigated whether dataset characteristics can predict the optimal `cells_across` parameter that minimizes error (distance from density peak to true cluster center).

### Study Configuration

- **Tool:** `research/cell_size_correlation_study.py`
- **Data Generator:** Enhanced `research/generate_test_data_with_clusters.py` with controllable ellipse size parameters
- **Factors Varied:** mean_semi_minor, semi_minor_cv (coefficient of variation), eccentricity, n_ellipses
- **Cell sizes tested:** cells_across = [5, 7, 10, 14, 20]

### Key Findings

#### 1. Mean Semi-Minor Axis

| Mean Semi-Minor | Optimal Cell Size | Ratio (cell/mean) | Error |
|-----------------|-------------------|-------------------|-------|
| 30m | 12.0m | 0.400 | 1040m |
| 60m | 23.9m | 0.400 | 1001m |
| 100m | 39.9m | 0.400 | 1012m |
| 150m | 42.7m | 0.286 | 1002m |
| 250m | 70.6m | 0.286 | 989m |

**Average ratio: 0.35** (std: 0.056, CV: 15.8%)

The ratio is moderately stable, suggesting `cell_size ≈ 0.35 × mean_semi_minor` as a rough formula.

#### 2. Coefficient of Variation (Most Significant Factor)

| CV | Optimal Cell Size | Ratio | Error |
|----|-------------------|-------|-------|
| 0.2 (low variability) | 40.0m | 0.400 | 595m |
| 0.4 | 28.5m | 0.286 | 280m |
| 0.6 | 19.9m | 0.200 | 284m |
| 0.8 (high variability) | 14.1m | 0.143 | 285m |

**Strong pattern:** Higher ellipse size variability requires finer resolution (smaller cells).

| CV | Recommended cells_across |
|----|-------------------------|
| < 0.3 | 5-7 (coarser) |
| 0.3-0.5 | 7-10 |
| > 0.5 | 10-14 (finer) |

#### 3. Eccentricity (Minor Effect)

Eccentricity (semi_major/semi_minor ratio) showed no consistent effect on optimal cell size. The high error values (~1400m) across all eccentricity values suggest eccentricity interacts with cluster placement rather than directly affecting resolution.

#### 4. Number of Ellipses

| n_ellipses | Optimal Cell Size | Error |
|------------|-------------------|-------|
| 5,000 | 11.0m | 2536m |
| 10,000 | 28.6m | 921m |
| 20,000 | 20.0m | 2898m |

Results are noisy due to cluster-to-noise ratio effects. More ellipses per cluster would improve accuracy.

### Recommendations

1. **Default `cells_across=10`** remains a reasonable middle-ground for datasets with moderate variability (CV ~0.4-0.6).

2. **For uniform ellipse sizes** (CV < 0.3): Consider `cells_across=5-7` for coarser but stable peaks.

3. **For highly variable ellipse sizes** (CV > 0.6): Consider `cells_across=14` for finer resolution.

4. **Future improvement:** The `compute_cell_size()` function could optionally factor in CV:
   ```python
   # Potential adaptive formula
   base_ratio = 0.35
   cv_adjustment = 1.0 - 0.5 * cv  # Reduce cell size for higher CV
   cell_size = base_ratio * cv_adjustment * mean_semi_minor
   ```

### Limitations

- Single cluster center per test (edge effects may skew results)
- Single random seed per configuration (statistical noise)
- Study focused on peak-finding accuracy, not overall density correlation

For rigorous production tuning, run the study with multiple seeds and verify against domain-specific accuracy requirements.

## Adaptive Cell Size Selection

Based on the correlation study findings, an adaptive cell size mode was implemented that automatically selects the optimal `cells_across` parameter based on the coefficient of variation (CV) of ellipse sizes in the dataset.

### Usage

```python
import density_analytical

# Fixed mode (default) - uses provided cells_across
result = density_analytical.run(data, cells_across=10, cell_size_mode="fixed")

# Auto mode - automatically selects cells_across based on CV
result, density, metadata = density_analytical.run(
    data,
    cell_size_mode="auto",
    return_density=True
)

# Check what cells_across was selected
print(f"CV: {metadata['semi_minor_cv']:.3f}")
print(f"Selected cells_across: {metadata['cells_across_effective']}")
```

### CV-to-Resolution Mapping

The adaptive formula maps CV to cells_across based on correlation study findings:

| CV Range | cells_across | Rationale |
|----------|--------------|-----------|
| < 0.3 | 5-7 | Uniform ellipses benefit from coarser grid |
| 0.3-0.5 | 7-10 | Moderate variability |
| > 0.5 | 10-14 | High variability requires finer resolution |

### Implementation Details

The `compute_adaptive_cells_across()` function uses piecewise linear interpolation:

```python
def compute_adaptive_cells_across(cv: float) -> int:
    if cv < 0.3:
        # Low variability: 5-7 cells
        return max(5, min(7, int(5 + (cv / 0.3) * 2)))
    elif cv < 0.5:
        # Medium variability: 7-10 cells
        return max(7, min(10, int(7 + ((cv - 0.3) / 0.2) * 3)))
    else:
        # High variability: 10-14 cells (cap CV at 1.0)
        normalized_cv = min(1.0, cv)
        return max(10, min(14, int(10 + ((normalized_cv - 0.5) / 0.5) * 4)))
```

### Metadata Output

When using `return_density=True`, the metadata includes:

- `semi_minor_cv`: Coefficient of variation of semi_minor values
- `cell_size_mode`: "fixed" or "auto"
- `cells_across_effective`: The actual cells_across used (may differ from requested in auto mode)

"""
Observations dataclass with integrated density computation methods.

This module provides:
- Observations dataclass for efficient numpy array-based data storage
- compute_adaptive_grid() method for grid specification
- compute_density_grid() method for analytical PDF density computation
- Pre-computed covariance support for performance
"""

from __future__ import annotations

import functools
import math
import warnings
from dataclasses import dataclass, field
from datetime import datetime

import numpy as np
from numpy.typing import NDArray
from scipy import stats
from numba import njit, prange, set_parallel_chunksize


# =============================================================================
# Constants
# =============================================================================

METERS_PER_DEGREE_LAT = 111_320
MIN_CELLSIZE_M = 11.0  # ~0.0001 degrees at equator
DEFAULT_CONFIDENCE = 0.95


# =============================================================================
# Helper Functions
# =============================================================================


@functools.cache
def chi2_for_confidence(confidence: float) -> float:
    """Get chi-squared value for given confidence level with 2 degrees of freedom."""
    return stats.chi2.ppf(confidence, 2)  # type: ignore


@functools.lru_cache(maxsize=128)
def meters_per_degree_lon(lat: float) -> float:
    """Compute meters per degree longitude at given latitude."""
    return METERS_PER_DEGREE_LAT * math.cos(math.radians(lat))


def precompute_covariances(
    semi_major: NDArray[np.float64],
    semi_minor: NDArray[np.float64],
    azimuth_deg: NDArray[np.float64],
    confidence: NDArray[np.float64],
) -> tuple[NDArray[np.float64], NDArray[np.float64], NDArray[np.float64]]:
    """
    Vectorized covariance matrix computation for multiple ellipses.

    For a 2x2 symmetric covariance matrix [[cov_00, cov_01], [cov_01, cov_11]],
    returns the three unique components.

    Args:
        semi_major: Array of semi-major axes in meters
        semi_minor: Array of semi-minor axes in meters
        azimuth_deg: Array of azimuths in degrees (clockwise from north)
        confidence: Array of confidence levels (0 to 1)

    Returns:
        Tuple of (cov_00, cov_01, cov_11) arrays
    """
    # Vectorized chi-squared computation
    chi2 = stats.chi2.ppf(confidence, 2)

    # Eigenvalues (variances along principal axes)
    lambda_major = (semi_major ** 2) / chi2
    lambda_minor = (semi_minor ** 2) / chi2

    # Rotation: azimuth is CW from north, convert to CCW from east
    theta = np.radians(90.0 - azimuth_deg)
    cos_t = np.cos(theta)
    sin_t = np.sin(theta)

    # Covariance matrix C = R @ D @ R.T
    cov_00 = lambda_major * cos_t**2 + lambda_minor * sin_t**2
    cov_01 = (lambda_major - lambda_minor) * cos_t * sin_t
    cov_11 = lambda_major * sin_t**2 + lambda_minor * cos_t**2

    return cov_00, cov_01, cov_11


def compute_cell_size(semi_minor_values: NDArray[np.float64], cells_across: int = 10, basis: str = "avg", mode: str = "fixed") -> tuple[float, int]:
    """
    Compute cell size based on ellipse sizes and target resolution.

    Args:
        semi_minor_values: Array of semi-minor axis values in meters
        cells_across: Target cells across ellipse diameter (used when mode="fixed")
        basis: How to compute reference size ("avg" or "p10")
        mode: Cell size mode - "fixed" uses provided cells_across,
              "auto" computes optimal cells_across from CV

    Returns:
        Tuple of (cell_size_m, effective_cells_across)
    """
    # In auto mode, compute CV and determine adaptive cells_across
    effective_cells_across = cells_across
    if mode == "auto":
        mean = np.mean(semi_minor_values)
        cv = float(np.std(semi_minor_values) / mean) if mean > 0 else 0.0
        effective_cells_across = compute_adaptive_cells_across(cv)
    elif mode != "fixed":
        raise ValueError(f"Unknown mode: {mode}. Use 'fixed' or 'auto'.")

    if basis == "avg":
        ref_size = np.mean(semi_minor_values)
    elif basis == "p10":
        ref_size = np.percentile(semi_minor_values, 10)
    else:
        raise ValueError(f"Unknown basis: {basis}. Use 'avg' or 'p10'.")

    # cells_across is across diameter (2 * semi_minor)
    cell_size_m = (2 * ref_size) / effective_cells_across

    # Floor at MIN_CELLSIZE_M to prevent excessive computation
    final_cell_size = float(max(MIN_CELLSIZE_M, cell_size_m))

    # Warn if floor was hit in auto mode (cell might be larger than optimal)
    if mode == "auto" and final_cell_size > cell_size_m:
        warnings.warn(f"Cell size floored at MIN_CELLSIZE_M ({MIN_CELLSIZE_M}m). "
                      f"Requested {cell_size_m:.1f}m with cells_across={effective_cells_across}.")

    return final_cell_size, effective_cells_across


def compute_adaptive_cells_across(cv: float) -> int:
    """
    Map coefficient of variation (CV) to recommended cells_across value.

    Based on correlation study findings:
    - Low CV (< 0.3): Uniform ellipses benefit from coarser grid (5-7)
    - Medium CV (0.3-0.5): Moderate variability (7-10)
    - High CV (> 0.5): High variability requires finer resolution (10-14)

    Args:
        cv: Coefficient of variation of semi_minor values (std/mean)

    Returns:
        Recommended cells_across value (5-14 range)
    """
    if cv < 0.3:
        # Low variability: 5-7 cells
        return max(5, min(7, int(5 + (cv / 0.3) * 2)))
    elif cv < 0.5:
        # Medium variability: 7-10 cells
        return max(7, min(10, int(7 + ((cv - 0.3) / 0.2) * 3)))
    else:
        # High variability: 10-14 cells (cap CV at 1.0 for formula)
        normalized_cv = min(1.0, cv)
        return max(10, min(14, int(10 + ((normalized_cv - 0.5) / 0.5) * 4)))

@dataclass
class GridSpec:
    """Grid specification for density computation."""
    lat_min: float
    lat_max: float
    lon_min: float
    lon_max: float

    n_lon: int

# =============================================================================
# Numba JIT Kernel
# =============================================================================


@njit(parallel=True, cache=True)
def _accumulate_density_numba(
    density: NDArray[np.float64],
    lat_coords_m: NDArray[np.float64],
    lon_coords_m: NDArray[np.float64],
    n_ellipses: int,
    centers_y_m: NDArray[np.float64],
    centers_x_m: NDArray[np.float64],
    cov_inv_00: NDArray[np.float64],
    cov_inv_01: NDArray[np.float64],
    cov_inv_11: NDArray[np.float64],
    norm_weights: NDArray[np.float64],
    bbox_radii_m: NDArray[np.float64],
    cutoff_mahal_sq: float,
    cell_size_lat_m: float,
    cell_size_lon_m: float,
    n_lat: int,
    n_lon: int,
) -> None:
    """
    JIT-compiled kernel for density accumulation.

    Uses prange for parallel execution. Parallelism is controlled via
    numba.set_parallel_chunksize() at the call site.
    """
    for idx in prange(n_ellipses):
        center_y = centers_y_m[idx]
        center_x = centers_x_m[idx]
        inv_00 = cov_inv_00[idx]
        inv_01 = cov_inv_01[idx]
        inv_11 = cov_inv_11[idx]
        norm_weight = norm_weights[idx]
        bbox_radius = bbox_radii_m[idx]

        # Compute bounding box indices
        lat_min_idx = max(0, int((center_y - bbox_radius) / cell_size_lat_m) - 1)
        lat_max_idx = min(n_lat, int((center_y + bbox_radius) / cell_size_lat_m) + 2)
        lon_min_idx = max(0, int((center_x - bbox_radius) / cell_size_lon_m) - 1)
        lon_max_idx = min(n_lon, int((center_x + bbox_radius) / cell_size_lon_m) + 2)

        # Skip if bounding box is empty
        if lat_min_idx >= lat_max_idx or lon_min_idx >= lon_max_idx:
            continue

        # Process bounding box
        for i in range(lat_min_idx, lat_max_idx):
            dy = lat_coords_m[i] - center_y
            dy_sq_inv11 = dy * dy * inv_11
            dy_2_inv01 = 2.0 * dy * inv_01

            for j in range(lon_min_idx, lon_max_idx):
                dx = lon_coords_m[j] - center_x

                # Mahalanobis distance squared
                mahal_sq = dx * dx * inv_00 + dx * dy_2_inv01 + dy_sq_inv11

                if mahal_sq <= cutoff_mahal_sq:
                    # Invert row index to match Monte Carlo coordinate convention
                    density[n_lat - 1 - i, j] += norm_weight * math.exp(-0.5 * mahal_sq)

@dataclass
class Observations:
    """
    Central data structure for geospatial observations with density computation.

    Pre-computes and caches numpy arrays for efficient algorithm access.
    Supports optional pre-computed covariances for performance.

    Attributes:
        n_observations: Total number of observations
        lats: Latitude values in degrees
        lons: Longitude values in degrees
        semi_major: Semi-major axis in meters
        semi_minor: Semi-minor axis in meters
        azimuth: Azimuth in degrees (clockwise from north)
        confidence: Confidence level (0-1, e.g., 0.95)
        cov_00, cov_01, cov_11: Pre-computed covariance matrix components
        timestamps: Datetime values (optional)
        device_ids: String device IDs (optional)
        source_indices: Original row indices from source data (optional)
    """

    # Metadata
    n_observations: int

    # Core position arrays
    lats: NDArray[np.float64]
    lons: NDArray[np.float64]

    # Error ellipse arrays
    semi_major: NDArray[np.float64]
    semi_minor: NDArray[np.float64]
    azimuth: NDArray[np.float64]
    confidence: NDArray[np.float64]

    # Pre-computed covariances (optional)
    cov_00: NDArray[np.float64] | None = None
    cov_01: NDArray[np.float64] | None = None
    cov_11: NDArray[np.float64] | None = None
    _covariances_computed: bool = field(default=False, repr=False)

    # Optional metadata
    timestamps: NDArray | None = None  # datetime64
    device_ids: list[str] | None = None
    source_indices: NDArray[np.int64] | None = None

    # Dwell weighting (optional)
    weights: NDArray[np.float64] | None = None  # Per-observation weights from dwell detection

    # =========================================================================
    # Computed properties
    # =========================================================================

    def ensure_covariances(self) -> None:
        """Compute and cache covariance components if not already done."""
        if self._covariances_computed:
            return

        self.cov_00, self.cov_01, self.cov_11 = precompute_covariances(self.semi_major, self.semi_minor, self.azimuth, self.confidence)
        self._covariances_computed = True

    @property
    def has_covariances(self) -> bool:
        """Check if covariances are pre-computed."""

        if self.n_observations == 0:
            return 0.0
        mean = np.mean(self.semi_minor)
        return float(np.std(self.semi_minor) / mean) if mean > 0 else 0.0

    @property
    def semi_minor_mean(self) -> float:
        """Mean semi_minor in meters."""
        return float(np.mean(self.semi_minor)) if self.n_observations > 0 else 0.0

        return float(np.std(self.semi_minor)) if self.n_observations > 0 else 0.0

    @property

        """Median semi_minor in meters."""
        return float(np.median(self.semi_minor)) if self.n_observations > 0 else 0.0

    @property
    def semi_major_mean(self) -> float:
        """Mean semi_major in meters."""
        return float(np.mean(self.semi_major)) if self.n_observations > 0 else 0.0

    @property
    def mean_eccentricity(self) -> float:
        """Mean eccentricity (semi_major/semi_minor ratio)."""
        if self.n_observations == 0:

        return float(np.mean(self.semi_major / self.semi_minor))

    def filter_by_device_id(self, device_id: str) -> Observations:

    def filter_by_time_range(self, start: datetime | None = None, end: datetime | None = None) -> Observations:
        """Return new Observations within time range."""
        if self.timestamps is None:

        if start is not None:

        if end is not None:

    def compute_adaptive_grid(self, cells_across: int = 10, cell_size_basis: str = "avg", cell_size_mode: str = "fixed", padding_factor: float = 1.5, max_dim: int = 2000, min_cells_across: int = 4) -> GridSpec:
        """
        Compute grid specification with configurable cell sizing.

        Args:
            cells_across: Target cells across ellipse diameter (default 10, used when mode="fixed")
            cell_size_basis: Method to compute reference ellipse size ("avg" or "p10")
            cell_size_mode: "fixed" uses provided cells_across, "auto" selects based on CV
            padding_factor: Factor to extend bounds beyond data extent
            max_dim: Maximum grid dimension (caps memory usage)
            min_cells_across: Minimum cells before warning

        Returns:
            GridSpec with computed resolution
        """
        if self.n_observations == 0:
            raise ValueError("No observations")

        # Direct array access (no list comprehension overhead)
        lat_min, lat_max = self.lats.min(), self.lats.max()
        lon_min, lon_max = self.lons.min(), self.lons.max()
        center_lat = self.center_lat

        # Compute cell size based on ellipse sizes (returns tuple with effective_cells_across)
        cell_size_m, effective_cells_across = compute_cell_size(self.semi_minor, cells_across, cell_size_basis, cell_size_mode)

        # Store original for warning calculation
        original_cell_size_m = cell_size_m

        # Add padding based on average semi-major
        avg_semi_major = self.semi_major.mean()
        padding_m = avg_semi_major * padding_factor

        # Convert padding to degrees
        padding_lat = padding_m / METERS_PER_DEGREE_LAT
        padding_lon = padding_m / meters_per_degree_lon(center_lat)

        lat_min -= padding_lat
        lat_max += padding_lat
        lon_min -= padding_lon
        lon_max += padding_lon

        # Calculate grid dimensions
        lat_extent_m = (lat_max - lat_min) * METERS_PER_DEGREE_LAT
        lon_extent_m = (lon_max - lon_min) * meters_per_degree_lon(center_lat)

        n_lat = max(10, int(lat_extent_m / cell_size_m))
        n_lon = max(10, int(lon_extent_m / cell_size_m))

        # Cap at maximum dimension to prevent memory issues
        if n_lat > max_dim or n_lon > max_dim:
            scale = max_dim / max(n_lat, n_lon)
            n_lat = int(n_lat * scale)
            n_lon = int(n_lon * scale)
            cell_size_m = original_cell_size_m / scale

            # Check if resolution dropped below minimum threshold
            ref_size = (self.semi_minor.mean() if cell_size_basis == "avg" else np.percentile(self.semi_minor, 10))
            actual_cells_across = (2 * ref_size) / cell_size_m
            if actual_cells_across < min_cells_across:
                warnings.warn(f"Grid resolution reduced: {actual_cells_across:.1f} cells across "
                              f"ellipse diameter (target: {cells_across}, min: {min_cells_across}). "
                              f"Consider increasing max_dim beyond {max_dim}."
                )

        return GridSpec(lat_min, lat_max, lon_min, lon_max, n_lat, n_lon, cell_size_m, effective_cells_across)

    def compute_density_grid(self, grid: GridSpec, cutoff_sigma: float = 3.0, parallel_threshold: int = 100) -> NDArray[np.float64]:
        """
        Compute combined probability density on a grid using precision-weighted summation.

        Each ellipse's contribution is weighted by:
            weight = precision * confidence_level

        Where precision = 1/sqrt(det(covariance)), giving higher weight to smaller,
        higher-confidence ellipses.

        Args:
            grid: Grid specification from compute_adaptive_grid()
            cutoff_sigma: Only compute density within this many sigma of each ellipse
            parallel_threshold: Min ellipses for parallel execution (default 100)

        Returns:
            2D density grid array with shape (n_lat, n_lon)
        """
        if self.n_observations == 0:
            return np.zeros((grid.n_lat, grid.n_lon), dtype=np.float64)

        # Ensure covariances are pre-computed
        self.ensure_covariances()

        # Create coordinate arrays
        lats = np.linspace(grid.lat_min, grid.lat_max, grid.n_lat)
        lons = np.linspace(grid.lon_min, grid.lon_max, grid.n_lon)

        # Initialize density accumulator
        density = np.zeros((grid.n_lat, grid.n_lon), dtype=np.float64)

        # Coordinate conversion factors (computed once)
        center_lat = (grid.lat_min + grid.lat_max) / 2
        m_per_deg_lon = meters_per_degree_lon(center_lat)

        # Pre-compute grid coordinates in meters (1D arrays)
        lon_coords_m = (lons - grid.lon_min) * m_per_deg_lon
        lat_coords_m = (lats - grid.lat_min) * METERS_PER_DEGREE_LAT

        # Grid cell sizes for bounding box computation
        cell_size_lon_m = (lons[1] - lons[0]) * m_per_deg_lon if len(lons) > 1 else 1.0
        cell_size_lat_m = (lats[1] - lats[0]) * METERS_PER_DEGREE_LAT if len(lats) > 1 else 1.0

        # Cutoff squared
        cutoff_mahal_sq = cutoff_sigma ** 2

        # Direct array access (no list comprehension - main optimization!)
        ellipse_lats = self.lats
        ellipse_lons = self.lons
        semi_majors = self.semi_major

        # Vectorized coordinate conversion
        centers_x_m = (ellipse_lons - grid.lon_min) * m_per_deg_lon
        centers_y_m = (ellipse_lats - grid.lat_min) * METERS_PER_DEGREE_LAT
        bbox_radii_m = semi_majors * cutoff_sigma

        # Use pre-computed covariances
        cov_00 = self.cov_00
        cov_01 = self.cov_01
        cov_11 = self.cov_11

        assert cov_00 is not None and cov_01 is not None and cov_11 is not None

        # Vectorized determinant and validity mask
        det_cov = cov_00 * cov_11 - cov_01**2
        valid_mask = det_cov > 0

        # Vectorized inverse (safe division to avoid divide-by-zero)
        inv_det = np.where(valid_mask, 1.0 / det_cov, 0.0)
        cov_inv_00 = cov_11 * inv_det
        cov_inv_01 = -cov_01 * inv_det
        cov_inv_11 = cov_00 * inv_det

        # Vectorized normalization weights (safe sqrt)
        sqrt_det = np.where(valid_mask, np.sqrt(det_cov), 1.0)
        norm_factor = 1.0 / (2.0 * np.pi * sqrt_det)
        precision = 1.0 / sqrt_det
        base_weights = norm_factor * precision * self.confidence

        # Apply dwell weights if present
        if self.weights is not None:
            base_weights = base_weights * self.weights

        norm_weights = np.where(valid_mask, base_weights, 0.0)

        # Filter to valid ellipses only
        n_valid = int(np.sum(valid_mask))

        if n_valid == 0:
            return density

        # Extract valid ellipse data
        centers_x_m = centers_x_m[valid_mask]
        centers_y_m = centers_y_m[valid_mask]
        cov_inv_00 = cov_inv_00[valid_mask]
        cov_inv_01 = cov_inv_01[valid_mask]
        cov_inv_11 = cov_inv_11[valid_mask]
        norm_weights = norm_weights[valid_mask]
        bbox_radii_m = bbox_radii_m[valid_mask]

        # Control parallelism via chunk size
        if n_valid < parallel_threshold:
            # Chunk larger than data = effectively single-threaded
            set_parallel_chunksize(n_valid + 1)
        else:
            # Use default chunking for parallel execution (0 = auto)
            set_parallel_chunksize(0)

        # Run JIT-compiled kernel
        _accumulate_density_numba(density, lat_coords_m, lon_coords_m, n_valid, centers_y_m, centers_x_m, cov_inv_00, cov_inv_01, cov_inv_11, norm_weights, bbox_radii_m,
                                  cutoff_mahal_sq, cell_size_lat_m, cell_size_lon_m, grid.n_lat, grid.n_lon)

        return density

def measure_peak_memory(func: Callable, *args, **kwargs) -> tuple[Any, float, float]:
    """
    Measure peak memory usage of a function call using tracemalloc.

    Returns:
        tuple: (result, peak_memory_mb, memory_increase_mb)
    """
    gc.collect()
    tracemalloc.start()
    try:
        baseline, _ = tracemalloc.get_traced_memory()
        result = func(*args, **kwargs)
        current, peak = tracemalloc.get_traced_memory()
        peak_mb = peak / (1024 * 1024)
        increase_mb = (current - baseline) / (1024 * 1024)
    finally:
        tracemalloc.stop()
    return result, peak_mb, max(0, increase_mb)


def measure_timed_runs(func: Callable, n_runs: int = 3) -> tuple[Any, float, float, float]:
    """
    Run function multiple times for timing.

    Returns:
        tuple: (result, mean_time, std_time, warmup_time)
    """
    # Warm-up run
    gc.collect()
    warmup_start = time.perf_counter()
    result = func()
    warmup_time = time.perf_counter() - warmup_start

    # Timed runs
    times = []
    for _ in range(n_runs):
        gc.collect()
        start = time.perf_counter()
        result = func()
        times.append(time.perf_counter() - start)

    mean_time = statistics.mean(times)
    std_time = statistics.stdev(times) if len(times) > 1 else 0.0

    return result, mean_time, std_time, warmup_time


def measure_cpu_utilization(func: Callable, interval: float = 0.1) -> tuple[Any, float]:
    """
    Measure CPU utilization during function execution.

    Returns:
        tuple: (result, cpu_percent)
    """
    if not PSUTIL_AVAILABLE:
        return func(), None

    process = psutil.Process()
    process.cpu_percent()  # First call to initialize

    result = func()
    cpu_percent = process.cpu_percent()

    return result, cpu_percent

        extra_info={"metadata": {k: v for k, v in metadata.items() if k != "grid_shape"}},
    )


def run_chunksize_tuning(data: pl.DataFrame, dataset_size: int, config: BenchmarkConfig, output_subdir: str, cluster_file: str | None = None) -> list[ChunksizeTuningResult]:
    """
    Test different parallel chunksize values for Numba optimization.

    Returns:
        List of ChunksizeTuningResult for each chunksize value
    """
    if not NUMBA_AVAILABLE:
        print("    Skipping chunksize tuning (numba chunksize API not available)")
        return []

    print(f"    Running chunksize tuning for {dataset_size:,} ellipses...")
    results = []
    auto_time = None

    for chunksize in config.chunksize_values:
        print(f"      Testing chunksize={chunksize}...", end=" ", flush=True)

        def run_with_chunksize():
            set_parallel_chunksize(chunksize)
            return run_analytical(data, config, output_subdir, cluster_file, chunksize=None)  # Already set

        # Run timed measurements
        _, mean_time, std_time, _ = measure_timed_runs(run_with_chunksize, n_runs=config.timed_runs)

        # Track auto (chunksize=0) time for speedup calculation
        if chunksize == 0:
            auto_time = mean_time

        speedup = auto_time / mean_time if auto_time and mean_time > 0 else None

        print(f"{mean_time:.2f}s")

        results.append(ChunksizeTuningResult(
            dataset_size=dataset_size,
            chunksize=chunksize,
            wall_time_seconds=mean_time,
            wall_time_std=std_time,
            speedup_vs_auto=speedup,
        ))

    # Reset to auto
    set_parallel_chunksize(0)

    return results


def find_optimal_chunksize(tuning_results: list[ChunksizeTuningResult]) -> dict:
    """
    Analyze tuning results and recommend optimal chunksize.

    Returns:
        Dict with recommendations per dataset size
    """
    recommendations = {}

    # Group by dataset size
    by_size = {}
    for result in tuning_results:
        if result.dataset_size not in by_size:
            by_size[result.dataset_size] = []
        by_size[result.dataset_size].append(result)

    for size, results in by_size.items():
        # Find fastest
        fastest = min(results, key=lambda r: r.wall_time_seconds)
        recommendations[size] = {
            "optimal_chunksize": fastest.chunksize,
            "optimal_time": fastest.wall_time_seconds,
            "all_results": [(r.chunksize, r.wall_time_seconds) for r in results],
        }

    return recommendations

def clean_data(data: pd.DataFrame,
               lat: str = "lat",
               lon: str = "lon",
               coordFormat: str = DECIMAL_DEGREES,
               major: str = "semimajor",
               minor: str = "semiminor",
               axisUnits: str = METERS,
               isSemi: bool = True,
               azimuth: str = "azimuth",
               azimuthUnits: str = DEGREES,
               id = None,
               **kwargs):
    
    df = data[[lat, lon, major]]
    df = df.rename(columns = {lat: "lat", lon: "lon", major: "semimajor"})

    minDF = data[[minor]]
    minDF = minDF.rename(columns = {minor: "semiminor"})

    df = df.join(minDF)

    if major == minor: # NOTE this is for CEP's where the major and minor are the same
        df["azimuth"] = 1
    else:
        azDF = data[[azimuth]]
        azDF = azDF.rename(columns = {azimuth: "azimuth"})
        df = df.join(azDF)

    if id is not None: # This is if they choose a id field
        idDF = data[[id]]
        idDF = idDF.rename(columns = {id : "identifier"})
        df = df.join(idDF)

    # Drop any null values
    log.debug(f"Rows before dropping nulls {df.shape[0]}")
    df = df.dropna()
    log.debug(f"Rows after dropping nulls {df.shape[0]}")

    if coordFormat == DECIMAL_DEGREES:
        df.lat = df.lat.astype(float)
        df.lon = df.lon.astype(float)
    else: # We have DMS
        df.lat = df.lat.apply(lambda a: float(a[0:2]) + (float(a[2:4]) / 60) + (float(a[4:6]) / 3600) if a[-1] == "N" else  
                                        (float(a[0:2]) + (float(a[2:4]) / 60) + (float(a[4:6]) / 3600)) * -1 if a[-1] == "S" else
                                        np.nan )
        df.lon = df.lon.apply(lambda a: float(a[:-5]) + (float(a[-5:-3]) / 60) + (float(a[-3:-1]) / 3600) if a[-1] == "E" else
                                        (float(a[:-5]) + (float(a[-5:-3]) / 60) + (float(a[-3:-1]) / 3600)) * -1 if a[-1] == "W" else
                                        np.nan)
    
    if axisUnits == METERS:
        df.semimajor = df.semimajor.astype(float)
        df.semiminor = df.semiminor.astype(float)
    elif axisUnits == KILOMETERS:
        df.semimajor = df.semimajor.apply(lambda x: float(x) * 1000.0)
        df.semiminor = df.semiminor.apply(lambda x: float(x) * 1000.0)
    else: # NOTE Nautical Miles
        df.semimajor = df.semimajor.apply(lambda x: float(x) * 1852.0)
        df.semiminor = df.semiminor.apply(lambda x: float(x) * 1852.0)
    
    if not isSemi:
        df.semimajor = df.semimajor.astype(float) / 2
        df.semiminor = df.semiminor.astype(float) / 2

    if azimuthUnits == DEGREES:
        df.azimuth = df.azimuth.apply(lambda x: np.radians(x))
    else: # NOTE Radians
        df.azimuth = df.azimuth.astype(float)

    return df

def calculate_factors(df: pd.DataFrame, conf: int = ELLIPSE, cell_size: str | float = AUTO_DETECT, sample_points: str | int = AUTO_DETECT, **kwargs):
    kay = np.sqrt((-2.0) * np.log(1.0 - (float(conf) / 100)))

    if cell_size == AUTO_DETECT:
        stats = df.semimajor.describe()
        cell_size = np.mean([stats.loc["min"], stats.loc["25%"]]) * 0.2 # type: ignore

    if sample_points == AUTO_DETECT:
        sample_points = int(df.semimajor.max())
        sample_points = min(sample_points, MAX_SAMPLEPOINTS)
        sample_points = max(sample_points, MIN_SAMPLEPOINTS)

    cell_size_ground = np.degrees(cell_size / EARTH_RADIUS_M) # type: ignore
    if cell_size_ground < MIN_CELLSIZE:
        cell_size_ground = MIN_CELLSIZE

    increment_value = 1.0 / sample_points # type: ignore

    return kay, int(cell_size), sample_points, cell_size_ground, increment_value

def marsaglia(major, minor, kay: float, n = 1):
    # Determine optimal number of samples to ensure we get n without having to loop
    x = (3 * np.sqrt(aux) + np.sqrt(9 * aux + p + n)) / p
    N = int(np.ceil(x * x))
    w1 = rng.uniform(-1.0, 1.0, N)
    w2 = rng.uniform(-1.0, 1.0, N)
    s = w1 ** 2.0 + w2 ** 2.0

    index = s < 1

    w1 = w1[index][:n]
    w2 = w2[index][:n]
    s = s[index][:n]

    t = np.sqrt(-2.0 * np.divide(np.log(s), s))

    z0 = (w1 * t) * minor / kay
    z1 = (w2 * t) * major / kay

    return z0, z1

def write_raster(output_dir: str, filename: str, data, origin, cell_size, cluster_file: str | None = None):
    SRS = osr.SpatialReference()
    SRS.ImportFromEPSG(4326)
    log.debug("using gdal write_raster")

    # Convert sparse matrix to dense array if needed
    if hasattr(data, 'toarray'):
        dense_data = data.toarray()
    else:
        dense_data = np.asarray(data)

    if dense_data.dtype == np.float64:
        arrType = gdal.GDT_Float64
    elif dense_data.dtype == np.float32:
        arrType = gdal.GDT_Float32
    else:
        arrType = gdal.GDT_Int32

    # Check to see if the output directory exists, if not create it
    if not os.path.exists(output_dir):
        os.makedirs(output_dir, exist_ok=True)

    # Make sure we have a file extension with the output
    if not (filename.endswith(".tiff") or filename.endswith(".tif")):
        filename = filename + ".tif"

    # Reverse the array so that it writes out correctly (flip vertically)
    rdata = dense_data[::-1]

    driver = gdal.GetDriverByName("GTiff")
    out = driver.Create(os.path.join(output_dir, filename), rdata.shape[1], rdata.shape[0], 1, arrType, GDAL_OPTIONS)
    out.SetProjection(SRS.ExportToWkt())
    # GeoTransform: (top_left_x, x_pixel_size, x_rotation, top_left_y, y_rotation, -y_pixel_size)
    # Note: y_pixel_size is negative because raster rows increase downward
    out.SetGeoTransform((origin[0], cell_size, 0, origin[1] + rdata.shape[0] * cell_size, 0, -cell_size))
    band = out.GetRasterBand(1)

    # Write entire array at once using WriteRaster (bypasses gdal_array requirement)
    band.WriteRaster(0, 0, rdata.shape[1], rdata.shape[0], rdata.tobytes())

    band.SetNoDataValue(0)
    band.FlushCache()
    band.ComputeStatistics(False)

    # This is needed to clean up gdal, otherwise it will keep the file handle open
    band = None
    driver = None
    out = None

    # Also write PNG for visual inspection
    # Calculate bounds for cluster plotting: (lon_min, lat_min, lon_max, lat_max)
    bounds = (
        origin[0],  # lon_min
        origin[1],  # lat_min
        origin[0] + dense_data.shape[1] * cell_size,  # lon_max
        origin[1] + dense_data.shape[0] * cell_size,  # lat_max
    )
    write_png(output_dir, filename, dense_data, bounds=bounds, cluster_file=cluster_file)

    return os.path.join(output_dir, filename)


def density(df: pd.DataFrame, kay: float, sample_points: int, cell_size_ground: float, increment_value: float):
    max_lat = np.max(df.lat + np.degrees((df.semimajor * 1.05) / EARTH_RADIUS_M))
    min_lat = np.min(df.lat - np.degrees((df.semimajor * 1.05) / EARTH_RADIUS_M))
    max_lon = np.max(df.lon + np.degrees((df.semimajor * 1.05) / (np.cos(np.radians(df.lat)) * EARTH_RADIUS_M)))
    min_lon = np.min(df.lon - np.degrees((df.semimajor * 1.05) / (np.cos(np.radians(df.lat)) * EARTH_RADIUS_M)))

    max_lat = (np.ceil(max_lat * 100000)) / 100000
    min_lat = (np.ceil(min_lat * 100000)) / 100000
    max_lon = (np.ceil(max_lon * 100000)) / 100000
    min_lon = (np.ceil(min_lon * 100000)) / 100000

    rows = int(np.ceil((max_lon - min_lon) / cell_size_ground))
    cols = int(np.ceil((max_lat - min_lat) / cell_size_ground))

    results = csr_matrix((cols, rows), dtype = np.float32)

    col_values = np.zeros(sample_points, dtype = int)
    row_values = np.zeros(sample_points, dtype = int)
    data = np.full(sample_points, increment_value)

    origin = [min_lon, min_lat]

    for row in df.itertuples():
        i = 0
        zxval, zyval = marsaglia(row.semimajor, row.semiminor, kay, sample_points)
        cazimuth = np.cos(row.azimuth) # type: ignore
        sazimuth = np.sin(row.azimuth) # type: ignore
        ddcenter  = EARTH_RADIUS_M * np.cos(np.radians(row.lat)) # type: ignore

        xval = zxval * cazimuth + zyval * sazimuth
        xvalddlon = np.degrees(xval / ddcenter) + row.lon
        xlonindxlow = np.floor((xvalddlon - min_lon) / cell_size_ground)
        cell_lon = min_lon + (xlonindxlow + 0.5) * cell_size_ground
        xlonindex = (xlonindxlow + np.less_equal(cell_lon, xvalddlon)).astype(int)

        yval = (-zxval * sazimuth) + zyval * cazimuth
        yvalddlat = np.degrees(yval / EARTH_RADIUS_M) + row.lat
        ylatindxlow = np.floor((yvalddlat - min_lat) / cell_size_ground)
        cell_lat = min_lat + (ylatindxlow + 0.5) * cell_size_ground
        ylatindex = (ylatindxlow + np.greater(cell_lat, yvalddlat)).astype(int)

        it = zip(xlonindex, ylatindex)
        for (x, y) in it:
            if (0 <= x < rows) and (0 <= y < cols): # We throw anything with an index < 0 out because its outside the image bounds
                col_values[i] = cols - y - 1
                row_values[i] = x
            i += 1
        
        results += csr_matrix((data, (col_values, row_values)), shape = (cols, rows))

    return results, origin

def run(data: pd.DataFrame, conf = ELLIPSE, lat = "lat", lon = "lon", coord_format = DECIMAL_DEGREES, major = "semi_major", minor = "semi_minor", axis_units = METERS,
        is_semi = True, azimuth = "azimuth", azimuth_units = DEGREES, cell_size = AUTO_DETECT, sample_points = AUTO_DETECT, output_dir = "output", output_name = "output.tiff",
        random_seed: int | None = None, return_density: bool = False, cluster_file: str | None = None):
    """

    Args:
        data: DataFrame with ellipse data
        conf: Confidence level (default 95 for ellipse)
        lat, lon: Column names for coordinates
        coord_format: Coordinate format (DD or DMS)
        major, minor: Column names for semi-major/minor axes
        axis_units: Units for axes (M, KM, or NM)
        is_semi: True if axes are semi-axes, False if full axes
        azimuth: Column name for azimuth
        azimuth_units: Units for azimuth (DEGREES or RADIANS)
        cell_size: Cell size in meters or AUTO_DETECT
        sample_points: Number of Monte Carlo samples or AUTO_DETECT
        output_dir: Directory for output file
        output_name: Name of output file
        random_seed: Optional seed for reproducible random sampling
        return_density: If True, also return the raw density array and metadata
        cluster_file: Optional path to cluster centers JSON file for visualization

    Returns:
        If return_density=False: path to output TIFF file
        If return_density=True: tuple of (file_path, density_array, metadata_dict)
    """
    global rng
    if random_seed is not None:
        rng = np.random.default_rng(random_seed)

    wdf = clean_data(data, lat, lon, coord_format, major, minor, axis_units, is_semi, azimuth, azimuth_units)
    kay, cell_size, sample_points, cell_size_ground, increment_value = calculate_factors(wdf, conf, cell_size, sample_points)
    results, origin = density(wdf, kay, sample_points, cell_size_ground, increment_value) # type: ignore
    result_file = write_raster(output_dir, output_name, results, origin, cell_size_ground, cluster_file=cluster_file)

    if return_density:
        metadata = {
            "origin": origin,
            "cell_size_ground": cell_size_ground,
            "sample_points": sample_points,
            "conf": conf,
            "random_seed": random_seed,
            "numpy_version": np.__version__,
            "shape": results.shape,
        }
        return result_file, results.toarray(), metadata

    return result_file

def write_png_rgba(output_dir: str, filename: str, data: NDArray, colormap: str = 'hot') -> str:
    """Write density array to PNG with RGBA (zero density = transparent).

    Creates a web-friendly PNG with transparent background for overlay on maps.
    Uses log scaling for better visualization of density variations.

    Args:
        output_dir: Directory to save PNG
        filename: Base filename
        data: Density array
        colormap: Matplotlib colormap name (default 'hot')

    Returns:
        Path to the saved PNG file
    """
    from matplotlib.colors import LogNorm

    # Ensure output directory exists
    if not os.path.exists(output_dir):
        os.makedirs(output_dir, exist_ok=True)

    # Generate RGBA PNG filename
    base_name = filename.replace(".tiff", "").replace(".tif", "").replace(".png", "")
    rgba_filename = base_name + "_rgba.png"

    # Flip array vertically to match raster convention (origin at top-left for image)
    rdata = data[::-1]

    # Get colormap (using non-deprecated API)
    cmap = plt.get_cmap(colormap)

    # Find valid data range for log scaling
    valid_data = rdata[rdata > 0]
    if len(valid_data) == 0:
        # No positive values, create fully transparent image
        rgba_array = np.zeros((rdata.shape[0], rdata.shape[1], 4), dtype=np.uint8)
    else:
        vmin = valid_data.min()
        vmax = valid_data.max()

        # Ensure at least 2 orders of magnitude for meaningful log scale
        if vmax / vmin < 100:
            vmin = vmax / 100

        # Normalize data using log scale
        norm = LogNorm(vmin=vmin, vmax=vmax)

        # Apply colormap to normalized data (only where data > 0)
        normalized = np.zeros_like(rdata, dtype=np.float64)
        mask = rdata > 0
        normalized[mask] = norm(rdata[mask])

        # Get RGBA values from colormap (returns float 0-1)
        rgba_float = cmap(normalized)

        # Convert to uint8 (0-255)
        rgba_array = (rgba_float * 255).astype(np.uint8)

        # Set alpha=0 where density=0 (transparent)
        rgba_array[~mask, 3] = 0

    # Save using Pillow
    img = Image.fromarray(rgba_array, mode='RGBA')
    output_path = os.path.join(output_dir, rgba_filename)
    img.save(output_path)

    return output_path


def compute_hexbins(density: NDArray, bounds: dict, h3_resolution: int = 10) -> list[dict]:
    """
    Aggregate density grid into H3 hexagons.

    For each grid cell with density > 0, maps to its H3 hex and accumulates density.

    Args:
        density: 2D density array (origin at bottom-left)
        bounds: Dict with lat_min, lat_max, lon_min, lon_max
        h3_resolution: H3 resolution (default 10, ~15m edge length)

    Returns:
        List of dicts with: h3_index, lat, lon, density
    """
    import h3

    lat_min, lat_max = bounds["lat_min"], bounds["lat_max"]
    lon_min, lon_max = bounds["lon_min"], bounds["lon_max"]
    n_rows, n_cols = density.shape

    # Compute actual cell sizes in degrees from grid dimensions
    cell_size_lat = (lat_max - lat_min) / n_rows
    cell_size_lon = (lon_max - lon_min) / n_cols

    # Accumulate density by H3 index
    hex_density: dict[str, float] = {}

    for row in range(n_rows):
        for col in range(n_cols):
            val = density[row, col]
            if val > 0:
                # Compute center of this grid cell
                lat = lat_min + (row + 0.5) * cell_size_lat
                lon = lon_min + (col + 0.5) * cell_size_lon

                # Get H3 index for this location
                h3_index = h3.latlng_to_cell(lat, lon, h3_resolution)

                # Accumulate density
                if h3_index in hex_density:
                    hex_density[h3_index] += val
                else:
                    hex_density[h3_index] = val

    # Convert to list of dicts with centroids
    result = []
    for h3_index, total_density in hex_density.items():
        lat, lon = h3.cell_to_latlng(h3_index)
        result.append({"h3_index": h3_index, "lat": lat, "lon": lon, "density": total_density})

    return result


def write_hexbins_geojson(hexbins: list[dict], output_path: str) -> str:
    """
    Write hexbins as GeoJSON FeatureCollection.

    Each feature has polygon geometry (H3 hex boundary) and properties (h3_index, density).

    Args:
        hexbins: List of dicts from compute_hexbins()
        output_path: Path to output GeoJSON file

    Returns:
        Path to the saved GeoJSON file
    """
    import h3

    features = []
    for hexbin in hexbins:
        # Get hex boundary as list of (lat, lon) tuples
        boundary = h3.cell_to_boundary(hexbin["h3_index"])
        # GeoJSON uses [lon, lat] order, and boundary needs to be closed (first point repeated at end)
        coords = [[lon, lat] for lat, lon in boundary]
        coords.append(coords[0])  # Close the polygon

        feature = {
            "type": "Feature",
            "geometry": {"type": "Polygon", "coordinates": [coords]},
            "properties": {"h3_index": hexbin["h3_index"], "density": hexbin["density"]},
        }
        features.append(feature)

    geojson = {"type": "FeatureCollection", "features": features}

    with open(output_path, "w") as f:
        json.dump(geojson, f)

    return output_path

def write_raster(output_dir: str, filename: str, data: NDArray, origin: tuple[float, float], cell_size: float, cluster_file: str | None = None) -> str:
    """Write density array to GeoTIFF file using rasterio.

    Args:
        output_dir: Directory to save the GeoTIFF
        filename: Output filename (will add .tif extension if needed)
        data: 2D density array
        origin: (lon_min, lat_min) tuple - bottom-left corner
        cell_size: Cell size in degrees
        cluster_file: Optional path to cluster centers JSON file for visualization

    Returns:
        Path to the saved GeoTIFF file
    """
    # Map numpy dtype to rasterio dtype
    if data.dtype == np.float64:
        rasterio_dtype = rasterio.float64
    elif data.dtype == np.float32:
        rasterio_dtype = rasterio.float32
    else:
        rasterio_dtype = rasterio.int32

    # Ensure output directory exists
    if not os.path.exists(output_dir):
        os.makedirs(output_dir, exist_ok=True)

    # Ensure file extension
    if not (filename.endswith(".tiff") or filename.endswith(".tif")):
        filename = filename + ".tif"

    # Reverse the array so that it writes out correctly (flip vertically)
    # Rasterio expects origin at top-left, but our data has origin at bottom-left
    rdata = data[::-1]

    # Calculate top-left corner for transform (rasterio uses top-left origin)
    top_left_x = origin[0]  # lon_min
    top_left_y = origin[1] + rdata.shape[0] * cell_size  # lat_max

    # Create rasterio profile
    # Affine transform: (x_scale, x_rotation, x_origin, y_rotation, y_scale, y_origin)
    # For geographic data: x_scale=cell_size, y_scale=-cell_size (negative because y decreases downward)
    profile = {
        'driver': 'GTiff',
        'height': rdata.shape[0],
        'width': rdata.shape[1],
        'count': 1,
        'dtype': rasterio_dtype,
        'crs': CRS.from_epsg(4326),
        'transform': Affine(cell_size, 0.0, top_left_x, 0.0, -cell_size, top_left_y),
        'compress': 'lzw',
        'nodata': 0,
    }

    # Write GeoTIFF
    output_path = os.path.join(output_dir, filename)
    with rasterio.open(output_path, 'w', **profile) as dst:
        dst.write(rdata, 1)

    # Calculate bounds for cluster plotting: (lon_min, lat_min, lon_max, lat_max)
    bounds = (
        origin[0],  # lon_min
        origin[1],  # lat_min
        origin[0] + data.shape[1] * cell_size,  # lon_max
        origin[1] + data.shape[0] * cell_size,  # lat_max
    )

    # Write PNG for visual inspection
    write_png(output_dir, filename, data, bounds=bounds, cluster_file=cluster_file)

    # Write RGBA PNG for web overlay
    write_png_rgba(output_dir, filename, data)

    return output_path


def clean_data(data: pl.DataFrame, lat: str = "lat", lon: str = "lon", major: str = "semi_major", minor: str = "semi_minor", azimuth: str = "azimuth",
               axis_units: str = METERS, is_semi: bool = True, azimuth_units: str = DEGREES, conf: float = 0.95, precompute_covariances_flag: bool = True,
               timestamp_col: str | None = None, device_id_col: str | None = None) -> Observations:
    """
    Clean and convert DataFrame to Observations.

    Args:
        data: DataFrame with ellipse data (Pandas or Polars)
        lat, lon: Column names for coordinates
        major, minor: Column names for semi-major/minor axes
        azimuth: Column name for azimuth
        axis_units: Units for axes (M, KM, or NM)
        is_semi: True if axes are semi-axes, False if full axes
        azimuth_units: Units for azimuth (DEGREES or RADIANS)
        conf: Confidence level (0 to 1)
        precompute_covariances_flag: Whether to pre-compute covariances (default True)
        timestamp_col: Column name for timestamps (optional, required for dwell detection)
        device_id_col: Column name for device IDs (optional, used for per-device dwell detection)

    Returns:
        Observations object with pre-computed arrays
    """
    # Handle empty DataFrame early
    if len(data) == 0:
        return Observations(n_observations = 0, lats = np.array([], dtype = np.float64), lons = np.array([], dtype = np.float64),
                            semi_major = np.array([], dtype = np.float64), semi_minor = np.array([], dtype = np.float64),
                            azimuth = np.array([], dtype = np.float64), confidence = np.array([], dtype = np.float64))

    # Build list of columns to select
    cols_to_select = [pl.col(lat).alias("lat"), pl.col(lon).alias("lon"), pl.col(major).alias("semi_major"), pl.col(minor).alias("semi_minor"), pl.col(azimuth).alias("azimuth")]

    # Add optional columns if specified and present
    if timestamp_col is not None and timestamp_col in data.columns:
        cols_to_select.append(pl.col(timestamp_col).alias("timestamp"))
    if device_id_col is not None and device_id_col in data.columns:
        cols_to_select.append(pl.col(device_id_col).alias("device_id"))

    df = data.select(cols_to_select).drop_nulls(subset=["lat", "lon", "semi_major", "semi_minor", "azimuth"])

    # Convert units using Polars expressions
    if axis_units == KILOMETERS:
        df = df.with_columns([(pl.col("semi_major") * 1000.0).alias("semi_major"),(pl.col("semi_minor") * 1000.0).alias("semi_minor")])
    elif axis_units == NAUTICAL_MILES:
        df = df.with_columns([(pl.col("semi_major") * 1852.0).alias("semi_major"), (pl.col("semi_minor") * 1852.0).alias("semi_minor")])

    # Convert full axes to semi
    if not is_semi:
        df = df.with_columns([(pl.col("semi_major") / 2).alias("semi_major"), (pl.col("semi_minor") / 2).alias("semi_minor")])

    # Convert azimuth to degrees if needed
    if azimuth_units == RADIANS:
        df = df.with_columns((pl.col("azimuth") * 180.0 / np.pi).alias("azimuth"))

    # Extract numpy arrays
    n = len(df)
    lats = df["lat"].to_numpy().astype(np.float64)
    lons = df["lon"].to_numpy().astype(np.float64)
    semi_major = df["semi_major"].to_numpy().astype(np.float64)
    semi_minor = df["semi_minor"].to_numpy().astype(np.float64)
    azimuth_arr = df["azimuth"].to_numpy().astype(np.float64)
    confidence = np.full(n, conf, dtype=np.float64)

    # Extract optional metadata
    timestamps = None
    device_ids = None
    if "timestamp" in df.columns:
        timestamps = df["timestamp"].to_numpy().astype('datetime64[ns]')
    if "device_id" in df.columns:
        device_ids = df["device_id"].to_list()

    # Pre-compute covariances if requested
    cov_00, cov_01, cov_11 = None, None, None
    covariances_computed = False
    if precompute_covariances_flag:
        cov_00, cov_01, cov_11 = precompute_covariances(semi_major, semi_minor, azimuth_arr, confidence)
        covariances_computed = True

    return Observations(n_observations = n, lats = lats, lons = lons, semi_major = semi_major, semi_minor = semi_minor, azimuth = azimuth_arr, confidence = confidence,
                        cov_00 = cov_00, cov_01 = cov_01, cov_11 = cov_11, _covariances_computed = covariances_computed, source_indices = np.arange(n, dtype = np.int64),
                        timestamps = timestamps, device_ids = device_ids)

"""
Density grid comparison utilities for regression testing.

Provides multiple metrics to compare density grids:
- RMSE: Root mean square error
- MAE: Mean absolute error
- Max diff: Maximum absolute difference
- Pearson r: Linear correlation coefficient
- SSIM: Structural similarity index
- Hotspot Jaccard: Overlap of high-density regions
"""

from dataclasses import dataclass
import numpy as np
from numpy.typing import NDArray
from scipy import stats

try:
    from skimage.metrics import structural_similarity as ssim
    HAS_SKIMAGE = True
except ImportError:
    HAS_SKIMAGE = False


@dataclass
class ComparisonResult:
    """Results from comparing two density grids."""
    identical: bool              # Byte-for-byte identical
    rmse: float                  # Root mean square error
    mae: float                   # Mean absolute error
    max_diff: float              # Maximum absolute difference
    pearson_r: float             # Pearson correlation coefficient
    ssim: float | None           # Structural similarity index (0-1), None if skimage not available
    hotspot_jaccard: float       # Overlap of top percentile density cells
    pass_threshold: bool         # True if within acceptable tolerance

    # Thresholds used for pass_threshold calculation
    tolerance_rmse: float = 0.0
    correlation_threshold: float = 0.0
    ssim_threshold: float = 0.0

    def __str__(self) -> str:
        """Human-readable summary."""
        status = "PASS" if self.pass_threshold else "FAIL"
        ssim_str = f"{self.ssim:.6f}" if self.ssim is not None else "N/A"
        return f"""Comparison Result: {status}
  Identical:        {self.identical}
  RMSE:             {self.rmse:.2e} (threshold: {self.tolerance_rmse:.2e})
  MAE:              {self.mae:.2e}
  Max Diff:         {self.max_diff:.2e}
  Pearson r:        {self.pearson_r:.6f} (threshold: {self.correlation_threshold:.6f})
  SSIM:             {ssim_str} (threshold: {self.ssim_threshold:.2f})
  Hotspot Jaccard:  {self.hotspot_jaccard:.4f}"""


def compare_density_grids(
    reference: NDArray[np.floating],
    candidate: NDArray[np.floating],
    tolerance_rmse: float = 1e-10,
    correlation_threshold: float = 0.9999,
    ssim_threshold: float = 0.99,
    hotspot_percentile: float = 99.0,
) -> ComparisonResult:
    """
    Compare two density grids and return detailed metrics.

    Args:
        reference: Reference density grid (2D array)
        candidate: Candidate density grid to compare (2D array)
        tolerance_rmse: Maximum acceptable RMSE for pass_threshold
        correlation_threshold: Minimum acceptable Pearson r for pass_threshold
        ssim_threshold: Minimum acceptable SSIM for pass_threshold
        hotspot_percentile: Percentile threshold for hotspot detection (default 99th)

    Returns:
        ComparisonResult with all computed metrics

    Raises:
        ValueError: If grids have different shapes
    """
    if reference.shape != candidate.shape:
        raise ValueError(
            f"Grid shapes do not match: reference {reference.shape} vs candidate {candidate.shape}"
        )

    # Convert to float64 for precision
    ref = reference.astype(np.float64)
    cand = candidate.astype(np.float64)

    # Check for identical arrays
    identical = np.array_equal(ref, cand)

    # Compute difference metrics
    diff = ref - cand
    rmse = float(np.sqrt(np.mean(diff ** 2)))
    mae = float(np.mean(np.abs(diff)))
    max_diff = float(np.max(np.abs(diff)))

    # Pearson correlation
    # Flatten arrays for correlation computation
    ref_flat = ref.ravel()
    cand_flat = cand.ravel()

    # Handle edge case where one or both arrays are constant
    if np.std(ref_flat) == 0 or np.std(cand_flat) == 0:
        if np.allclose(ref_flat, cand_flat):
            pearson_r = 1.0
        else:
            pearson_r = 0.0
    else:
        pearson_r, _ = stats.pearsonr(ref_flat, cand_flat)
        pearson_r = float(pearson_r)

    # SSIM (requires scikit-image)
    ssim_value: float | None = None
    if HAS_SKIMAGE:
        # Normalize to 0-1 range for SSIM
        ref_max = ref.max()
        cand_max = cand.max()
        if ref_max > 0 and cand_max > 0:
            ref_norm = ref / ref_max
            cand_norm = cand / cand_max
            ssim_value = float(ssim(ref_norm, cand_norm, data_range=1.0))
        else:
            ssim_value = 1.0 if np.allclose(ref, cand) else 0.0

    # Hotspot Jaccard index
    hotspot_jaccard = _compute_hotspot_jaccard(ref, cand, hotspot_percentile)

    # Determine if within acceptable thresholds
    pass_threshold = (
        rmse <= tolerance_rmse and
        pearson_r >= correlation_threshold and
        (ssim_value is None or ssim_value >= ssim_threshold)
    )

    return ComparisonResult(
        identical=identical,
        rmse=rmse,
        mae=mae,
        max_diff=max_diff,
        pearson_r=pearson_r,
        ssim=ssim_value,
        hotspot_jaccard=hotspot_jaccard,
        pass_threshold=pass_threshold,
        tolerance_rmse=tolerance_rmse,
        correlation_threshold=correlation_threshold,
        ssim_threshold=ssim_threshold,
    )


def _compute_hotspot_jaccard(
    ref: NDArray[np.float64],
    cand: NDArray[np.float64],
    percentile: float = 99.0,
) -> float:
    """
    Compute Jaccard index for high-density (hotspot) regions.

    This measures how well the candidate grid identifies the same
    hotspot locations as the reference grid.

    Args:
        ref: Reference density grid
        cand: Candidate density grid
        percentile: Percentile threshold for hotspot detection

    Returns:
        Jaccard index (0-1) measuring overlap of hotspot regions
    """
    # Get threshold values for hotspots
    ref_threshold = np.percentile(ref, percentile)
    cand_threshold = np.percentile(cand, percentile)

    # Create binary masks for hotspots
    ref_hotspots = ref >= ref_threshold
    cand_hotspots = cand >= cand_threshold

    # Compute Jaccard index: intersection / union
    intersection = np.sum(ref_hotspots & cand_hotspots)
    union = np.sum(ref_hotspots | cand_hotspots)

    if union == 0:
        return 1.0  # Both have no hotspots - consider identical

    return float(intersection / union)


def compare_with_tolerance(
    reference: NDArray[np.floating],
    candidate: NDArray[np.floating],
    mode: str = "same_seed",
) -> ComparisonResult:
    """
    Compare grids using pre-defined tolerance levels.

    Args:
        reference: Reference density grid
        candidate: Candidate density grid
        mode: Comparison mode:
            - "same_seed": Very tight tolerance for reproducible runs
            - "different_seed": Looser tolerance for statistical comparison
            - "algorithm_change": Even looser for expected algorithmic differences

    Returns:
        ComparisonResult with appropriate thresholds
    """
    if mode == "same_seed":
        return compare_density_grids(
            reference, candidate,
            tolerance_rmse=1e-10,
            correlation_threshold=0.9999,
            ssim_threshold=0.99,
        )
    elif mode == "different_seed":
        # Looser thresholds for Monte Carlo variance
        max_val = max(reference.max(), candidate.max())
        return compare_density_grids(
            reference, candidate,
            tolerance_rmse=0.01 * max_val,
            correlation_threshold=0.95,
            ssim_threshold=0.90,
        )
    elif mode == "algorithm_change":
        # Even looser for expected differences (e.g., precision weighting)
        max_val = max(reference.max(), candidate.max())
        return compare_density_grids(
            reference, candidate,
            tolerance_rmse=0.1 * max_val,
            correlation_threshold=0.80,
            ssim_threshold=0.70,
        )
    else:
        raise ValueError(f"Unknown mode: {mode}. Use 'same_seed', 'different_seed', or 'algorithm_change'")

## Option E: FastAPI + SvelteKit + deck.gl Standalone (New Recommendation)

**Philosophy**: Clean architecture with optimal mapping performance, minimal dependencies, and approachable frontend

### Why This Option?

Based on [deck.gl maintainer guidance](https://github.com/visgl/deck.gl/discussions/8941#discussioncomment-9833122), **combining deck.gl and Leaflet is not recommended** for high-performance use cases due to "overlaying two canvases."

For your use case (raster imagery base layers + basic pan/zoom), **deck.gl standalone** is the simplest solution:
- Single library handles base tiles, data overlay, and raster display
- No MapLibre needed (you don't need vector labels or advanced map controls)
- One WebGL context = optimal performance
- Less code, fewer dependencies

### Why deck.gl Standalone (No MapLibre)?

For raster imagery base layers with basic pan/zoom, deck.gl handles everything:

```javascript

new Deck({
  initialViewState: {
    longitude: -83.6,
    latitude: 32.83,
    zoom: 11

      id: 'esri-base',
      data: 'https://your-esri-server/arcgis/rest/services/Imagery/MapServer/tile/{z}/{y}/{x}',

        image: props.data,
        bounds: [
          props.tile.boundingBox[0][0], props.tile.boundingBox[0][1],
          props.tile.boundingBox[1][0], props.tile.boundingBox[1][1]
        ]
      })

      id: 'observations',
      data: observations,

      getRadius: d => d.semi_major,
      getFillColor: [255, 140, 0, 150]
    }),

      id: 'density',

```

        url: 'https://your-esri-server/arcgis/rest/services/Imagery/MapServer'
      })

    // Observation ellipses (WebGL for 10k+ features)

        'circle-stroke-width': 1
      }

    // Density COG raster (native GeoTIFF support)

        sources: [{ url: 'https://minio/outputs/density.cog.tif' }]
      }),
      opacity: 0.7
    })
  ]
});

## Recommendation

### Primary: Option E (FastAPI + SvelteKit + deck.gl Standalone)

**Rationale**:
1. **Optimal map performance** - deck.gl standalone uses single WebGL context (no dual-canvas issue)
2. **Minimal dependencies** - One mapping library handles base tiles, data overlays, and rasters
3. **Native ESRI tile support** - TileLayer works directly with your `{z}/{y}/{x}` tile servers
4. **Best API design** - FastAPI auto-generates OpenAPI docs, great for other data science consumers
5. **Approachable frontend** - SvelteKit is much easier than React, syntax close to vanilla HTML
6. **Clean architecture** - Clear separation of Python backend and lightweight JS frontend

**Trade-off**: Requires learning basic JavaScript/SvelteKit (~2-3 weeks), but this investment pays off in:
- Proper mapping performance (per deck.gl maintainer recommendations)
- Simpler architecture (one mapping library vs two)
- Better UI flexibility and polish

### Alternative: Option E1 (FastAPI + SvelteKit + OpenLayers)

**Consider E1 instead of E if**:
- You anticipate needing WMS, WFS, or WMTS services beyond ESRI tiles
- Your team has GIS background and prefers traditional GIS library concepts
- You want comprehensive built-in map controls (scale bar, overview map, etc.)
- You might add vector tiles or other OGC-compliant services later

**Trade-off vs E**: Slightly steeper learning curve (~1 extra week), but you get comprehensive GIS standards support and more built-in features.

### Secondary: Option A (Enhanced Dash Stack)

**Consider if**:
- Team strongly prefers zero JavaScript
- You can accept the dual-canvas performance limitations
- Simpler operations (single Python deployment) is critical

**Important caveat**: The [deck.gl + Leaflet combination is explicitly not recommended](https://github.com/visgl/deck.gl/discussions/8941#discussioncomment-9833122) by maintainers for high-performance use cases. If you go this route:
- Use Dash Leaflet for base maps (your ESRI tiles)
- Accept that deck.gl overlay will have performance overhead
- Or use Dash Leaflet only (without deck.gl) and accept Leaflet's limitations at 10k+ features

### Not Recommended: Options C & D

- **Option C (Panel)**: Steeper learning curve, limited WMS/ESRI support
- **Option D (Streamlit)**: Poor mapping capabilities, scalability issues at 50+ users

===== FILE: dwell_detection.py =====
"""
Dwell time detection for geospatial observations.

This module identifies stationary periods (dwells) in observation data and computes
weights based on time spent at location. Observations during dwells are weighted
by duration to give more significance to locations where a device spent more time.

Key concepts:
- Dwell: A cluster of consecutive observations where the device remained stationary
- Transit: Observations that don't belong to a valid dwell (weight = 1.0)
- Weight: Computed as (dwell_duration / n_observations) / reference_rate
"""

from __future__ import annotations

from dataclasses import dataclass, field
import numpy as np
from numpy.typing import NDArray

from Observations import Observations, METERS_PER_DEGREE_LAT, meters_per_degree_lon


# =============================================================================
# Constants
# =============================================================================

DEFAULT_REFERENCE_RATE_SEC = 60.0  # 1 observation per minute = weight 1.0


# =============================================================================
# Configuration Dataclass
# =============================================================================


@dataclass
class DwellConfig:
    """Configuration parameters for dwell detection."""
    min_observations: int = 3              # Minimum observations for valid dwell
    min_dwell_time_sec: float = 300.0      # Minimum duration for valid dwell (5 minutes)
    max_dwell_radius_m: float = 100.0      # Maximum spatial radius from centroid
    max_time_gap_sec: float = 1800.0       # Maximum gap between consecutive observations (30 minutes)
    per_device: bool = True                # False = global (all observations together)
    reference_rate_sec: float = DEFAULT_REFERENCE_RATE_SEC  # Reference rate for weight computation


# =============================================================================
# Result Dataclasses
# =============================================================================


@dataclass
class DwellPeriod:
    """Represents a single detected dwell period."""
    dwell_id: int
    device_id: str | None                   # Which device (None if global mode)
    observation_indices: NDArray[np.int64]  # Indices into original observations
    start_time_sec: float                   # Start timestamp (seconds since epoch)
    end_time_sec: float                     # End timestamp (seconds since epoch)
    duration_sec: float                     # Total dwell duration
    centroid_lat: float                     # Centroid latitude
    centroid_lon: float                     # Centroid longitude
    n_observations: int                     # Number of observations in this dwell


@dataclass
class DwellResult:
    """Complete result of dwell detection."""
    config: DwellConfig
    dwells: list[DwellPeriod]
    dwell_membership: NDArray[np.int64]      # Per-obs dwell ID (-1 = transit)
    observation_weights: NDArray[np.float64]  # Per-obs weights
    n_dwell_observations: int
    n_transit_observations: int
    total_dwell_time_sec: float


# =============================================================================
# Helper Functions
# =============================================================================


def _haversine_distance_m(lat1: float, lon1: float, lat2: float, lon2: float) -> float:
    """
    Compute Haversine distance between two points in meters.

    Uses simplified flat-earth approximation which is accurate enough for
    short distances (< 100km) typical in dwell detection.
    """
    # Use simple flat-earth approximation for speed (accurate at dwell scales)
    center_lat = (lat1 + lat2) / 2
    m_per_deg_lon = meters_per_degree_lon(center_lat)

    dlat_m = (lat2 - lat1) * METERS_PER_DEGREE_LAT
    dlon_m = (lon2 - lon1) * m_per_deg_lon

    return np.sqrt(dlat_m ** 2 + dlon_m ** 2)


def _compute_centroid(lats: NDArray[np.float64], lons: NDArray[np.float64]) -> tuple[float, float]:
    """Compute centroid of a set of points."""
    return float(np.mean(lats)), float(np.mean(lons))


def _distance_from_centroid(lat: float, lon: float, centroid_lat: float, centroid_lon: float) -> float:
    """Compute distance from a point to a centroid in meters."""
    return _haversine_distance_m(lat, lon, centroid_lat, centroid_lon)


# =============================================================================
# Core Detection Functions
# =============================================================================


def _detect_dwells_for_device(indices: NDArray[np.int64], timestamps_sec: NDArray[np.float64], lats: NDArray[np.float64], lons: NDArray[np.float64],
                              device_id: str | None, config: DwellConfig, next_dwell_id: int) -> tuple[list[DwellPeriod], int]:
    """
    Detect dwells for a single device's observations.

    Args:
        indices: Original indices of these observations
        timestamps_sec: Timestamps in seconds since epoch (sorted)
        lats: Latitude values (in same order as timestamps)
        lons: Longitude values (in same order as timestamps)
        device_id: Device identifier (None for global mode)
        config: Dwell detection configuration
        next_dwell_id: Starting ID for dwells found

    Returns:
        Tuple of (list of DwellPeriod objects, next available dwell_id)
    """
    n = len(indices)
    if n == 0:
        return [], next_dwell_id

    # Sort by timestamp
    sort_order = np.argsort(timestamps_sec)
    sorted_indices = indices[sort_order]
    sorted_times = timestamps_sec[sort_order]
    sorted_lats = lats[sort_order]
    sorted_lons = lons[sort_order]

    dwells: list[DwellPeriod] = []
    current_cluster_indices: list[int] = []
    current_cluster_sorted_positions: list[int] = []

    def finalize_cluster() -> None:
        """Check if current cluster is a valid dwell and save it."""
        nonlocal next_dwell_id

        if len(current_cluster_sorted_positions) < config.min_observations:
            return

        pos = np.array(current_cluster_sorted_positions)
        cluster_times = sorted_times[pos]
        cluster_lats = sorted_lats[pos]
        cluster_lons = sorted_lons[pos]

        duration = cluster_times[-1] - cluster_times[0]
        if duration < config.min_dwell_time_sec:
            return

        # Valid dwell
        centroid_lat, centroid_lon = _compute_centroid(cluster_lats, cluster_lons)

        dwell = DwellPeriod(
            dwell_id=next_dwell_id,
            device_id=device_id,
            observation_indices=sorted_indices[pos].copy(),
            start_time_sec=float(cluster_times[0]),
            end_time_sec=float(cluster_times[-1]),
            duration_sec=float(duration),
            centroid_lat=centroid_lat,
            centroid_lon=centroid_lon,
            n_observations=len(pos),
        )
        dwells.append(dwell)
        next_dwell_id += 1

    # Iterate through sorted observations
    for i in range(n):
        if len(current_cluster_sorted_positions) == 0:
            # Start new cluster
            current_cluster_sorted_positions.append(i)
            continue

        # Check time gap from previous observation
        time_gap = sorted_times[i] - sorted_times[current_cluster_sorted_positions[-1]]
        if time_gap > config.max_time_gap_sec:
            finalize_cluster()
            current_cluster_sorted_positions = [i]
            continue

        # Compute centroid of current cluster
        pos = np.array(current_cluster_sorted_positions)
        centroid_lat, centroid_lon = _compute_centroid(sorted_lats[pos], sorted_lons[pos])

        # Check distance from current observation to cluster centroid
        dist = _distance_from_centroid(sorted_lats[i], sorted_lons[i], centroid_lat, centroid_lon)
        if dist > config.max_dwell_radius_m:
            finalize_cluster()
            current_cluster_sorted_positions = [i]
            continue

        # Add to current cluster
        current_cluster_sorted_positions.append(i)

    # Finalize last cluster
    finalize_cluster()

    return dwells, next_dwell_id


def _compute_weights(n_observations: int, dwells: list[DwellPeriod], config: DwellConfig) -> tuple[NDArray[np.int64], NDArray[np.float64]]:
    """
    Compute per-observation weights based on detected dwells.

    Weight formula: (dwell_duration / n_obs_in_dwell) / reference_rate
    - Dwell with 10 obs over 1 hour: (3600/10)/60 = 6.0
    - Dwell with 10 obs over 10 min: (600/10)/60 = 1.0
    - Transit observations: 1.0

    Args:
        n_observations: Total number of observations
        dwells: List of detected dwells
        config: Configuration with reference_rate_sec

    Returns:
        Tuple of (dwell_membership array, weights array)
    """
    dwell_membership = np.full(n_observations, -1, dtype=np.int64)
    weights = np.ones(n_observations, dtype=np.float64)

    for dwell in dwells:
        # Mark membership
        dwell_membership[dwell.observation_indices] = dwell.dwell_id

        # Compute weight for this dwell
        time_per_obs = dwell.duration_sec / dwell.n_observations
        weight = time_per_obs / config.reference_rate_sec

        # Apply weight to all observations in this dwell
        weights[dwell.observation_indices] = weight

    return dwell_membership, weights

def detect_dwells(observations: Observations, config: DwellConfig | None = None) -> DwellResult:
    """
    Detect dwell periods in observations and compute observation weights.

    Dwell detection uses sequential temporal clustering per device:
    1. Group observations by device_id (if per_device=True)
    2. Sort by timestamp within each device
    3. Form clusters when consecutive observations are within time/space thresholds
    4. Validate clusters meet minimum size/duration requirements

    Args:
        observations: Observations object with timestamps and optionally device_ids
        config: DwellConfig with detection parameters (uses defaults if None)

    Returns:
        DwellResult with detected dwells and per-observation weights

    Raises:
        ValueError: If observations have no timestamps
    """
    if config is None:
        config = DwellConfig()

    n = observations.n_observations

    # Handle edge case: no observations
    if n == 0:
        return DwellResult(
            config=config,
            dwells=[],
            dwell_membership=np.array([], dtype=np.int64),
            observation_weights=np.array([], dtype=np.float64),
            n_dwell_observations=0,
            n_transit_observations=0,
            total_dwell_time_sec=0.0,
        )

    # Validate timestamps exist
    if observations.timestamps is None:
        raise ValueError("Dwell detection requires timestamps. Set enable_dwell_weighting=False or provide timestamp data.")

    # Convert timestamps to seconds since epoch
    timestamps_sec = observations.timestamps.astype('datetime64[s]').astype(np.float64)

    # Get all indices
    all_indices = np.arange(n, dtype=np.int64)

    all_dwells: list[DwellPeriod] = []
    next_dwell_id = 0

    if config.per_device and observations.device_ids is not None:
        # Process each device separately
        unique_devices = list(set(observations.device_ids))

        for device_id in unique_devices:
            # Get indices for this device
            device_mask = np.array([d == device_id for d in observations.device_ids], dtype=bool)
            device_indices = all_indices[device_mask]

            if len(device_indices) == 0:
                continue

            dwells, next_dwell_id = _detect_dwells_for_device(
                indices=device_indices,
                timestamps_sec=timestamps_sec[device_mask],
                lats=observations.lats[device_mask],
                lons=observations.lons[device_mask],
                device_id=device_id,
                config=config,
                next_dwell_id=next_dwell_id,
            )
            all_dwells.extend(dwells)
    else:
        # Global mode: treat all observations as one device
        dwells, next_dwell_id = _detect_dwells_for_device(
            indices=all_indices,
            timestamps_sec=timestamps_sec,
            lats=observations.lats,
            lons=observations.lons,
            device_id=None,
            config=config,
            next_dwell_id=next_dwell_id,
        )
        all_dwells.extend(dwells)

    # Compute weights
    dwell_membership, weights = _compute_weights(n, all_dwells, config)

    # Compute statistics
    n_dwell_obs = int(np.sum(dwell_membership >= 0))
    n_transit_obs = n - n_dwell_obs
    total_dwell_time = sum(d.duration_sec for d in all_dwells)

    return DwellResult(
        config=config,
        dwells=all_dwells,
        dwell_membership=dwell_membership,
        observation_weights=weights,
        n_dwell_observations=n_dwell_obs,
        n_transit_observations=n_transit_obs,
        total_dwell_time_sec=total_dwell_time,
    )

"""
Error estimation model for density peak location uncertainty.

Uses empirical data from the correlation study to estimate expected error
based on dataset characteristics. The model interpolates from study results
to provide error bounds for arbitrary input parameters.
"""

import json
from collections.abc import Sequence
from dataclasses import dataclass
from pathlib import Path

import numpy as np


@dataclass
class ErrorEstimate:
    """
    Error estimate result for density peak location.

    Attributes:
        expected_peak_error_m: Expected distance from density peak to true center (meters)
        peak_error_std_m: Standard deviation of peak error across seeds (meters)
        expected_centroid_error_m: Expected distance from density-weighted centroid to true center (meters)
        centroid_error_std_m: Standard deviation of centroid error (meters)
        confidence_interval_95_m: 95% confidence interval for peak error (low, high) in meters
        factors: Input factors used for the estimate
        low_confidence: True if estimated error exceeds cell_size (results may be unreliable)
        warning_message: Explanation message if low_confidence is True
    """
    expected_peak_error_m: float
    peak_error_std_m: float
    expected_centroid_error_m: float
    centroid_error_std_m: float
    confidence_interval_95_m: tuple[float, float]
    factors: dict
    low_confidence: bool
    warning_message: str | None


# Studied parameter ranges from correlation study
STUDIED_MEAN_SEMI_MINOR = [30, 60, 100, 150, 250]
STUDIED_CV = [0.2, 0.4, 0.6, 0.8]
STUDIED_N_ELLIPSES = [5000, 10000, 20000]


def load_correlation_study_data() -> dict:
    """
    Load correlation study results from JSON file.

    Returns:
        Dict with study configuration names as keys
    """
    study_path = Path(__file__).parent / "test_data" / "correlation_study" / "correlation_study_results.json"
    if not study_path.exists():
        raise FileNotFoundError(f"Correlation study data not found at {study_path}. Run research/cell_size_correlation_study.py first.")
    with open(study_path) as f:
        return json.load(f)


def _find_nearest_values(target: float, values: Sequence[float]) -> tuple[float, float, float]:
    """
    Find the two nearest values in a sorted list and compute interpolation weight.

    Returns:
        (lower_value, upper_value, weight) where weight is for upper_value (0-1)
    """
    values = sorted(values)

    if target <= values[0]:
        return values[0], values[0], 0.0
    if target >= values[-1]:
        return values[-1], values[-1], 0.0

    for i in range(len(values) - 1):
        if values[i] <= target <= values[i + 1]:
            span = values[i + 1] - values[i]
            weight = (target - values[i]) / span if span > 0 else 0.0
            return values[i], values[i + 1], weight

    return values[-1], values[-1], 0.0


def _get_config_key_for_mean(mean_val: float) -> str:
    """Get the configuration key for a mean_semi_minor value."""
    return f"mean_{int(mean_val)}"


def _get_config_key_for_cv(cv_val: float) -> str:
    """Get the configuration key for a CV value."""
    return f"cv_{cv_val:.1f}"


def _get_config_key_for_n(n_val: int) -> str:
    """Get the configuration key for n_ellipses value."""
    return f"n_{int(n_val)}"


def _extract_optimal_errors(config_data: dict) -> tuple[float, float, float]:
    """
    Extract error metrics from the optimal cells_across configuration.

    Returns:
        (mean_error_m, std_error_m, centroid_error_m)
    """
    if "optimal_stats" in config_data and config_data["optimal_stats"]:
        optimal_cells = config_data["optimal_stats"].get("optimal_cells_across", 10)
    else:
        optimal_cells = 10

    for result in config_data.get("aggregated_results", []):
        if result["cells_across"] == optimal_cells:
            return (result["mean_error_m"], result["std_error_m"], result["mean_centroid_error_m"])

    # Fallback to first result
    if config_data.get("aggregated_results"):
        r = config_data["aggregated_results"][0]
        return (r["mean_error_m"], r["std_error_m"], r["mean_centroid_error_m"])

    return (1500.0, 500.0, 1200.0)  # Conservative defaults


def _interpolate_errors(study_data: dict, mean_semi_minor: float, cv: float, n_observations: int) -> tuple[float, float, float]:
    """
    Interpolate error estimates from study data based on input parameters.

    Uses nearest-neighbor interpolation with weighted averaging for each dimension.

    Returns:
        (expected_peak_error, peak_error_std, expected_centroid_error)
    """
    errors = []
    weights = []

    # Strategy: Find matching configurations and weight by parameter similarity
    # We prioritize mean_semi_minor as the primary factor since error scales with ellipse size

    # 1. Get errors from mean_semi_minor study
    lower_mean, upper_mean, mean_weight = _find_nearest_values(mean_semi_minor, STUDIED_MEAN_SEMI_MINOR)
    for studied_mean, weight in [(lower_mean, 1 - mean_weight), (upper_mean, mean_weight)]:
        if weight > 0:
            key = _get_config_key_for_mean(studied_mean)
            if key in study_data:
                peak_err, peak_std, centroid_err = _extract_optimal_errors(study_data[key])
                # Scale error proportionally to mean_semi_minor difference
                scale_factor = mean_semi_minor / studied_mean if studied_mean > 0 else 1.0
                errors.append((peak_err * scale_factor, peak_std * scale_factor, centroid_err * scale_factor))
                weights.append(weight * 2.0)  # Higher weight for mean_semi_minor matches

    # 2. Get errors from CV study (secondary factor)
    lower_cv, upper_cv, cv_weight = _find_nearest_values(cv, STUDIED_CV)
    for studied_cv, weight in [(lower_cv, 1 - cv_weight), (upper_cv, cv_weight)]:
        if weight > 0:
            key = _get_config_key_for_cv(studied_cv)
            if key in study_data:
                peak_err, peak_std, centroid_err = _extract_optimal_errors(study_data[key])
                # Scale by mean_semi_minor ratio (CV study used mean=100)
                scale_factor = mean_semi_minor / 100.0
                errors.append((peak_err * scale_factor, peak_std * scale_factor, centroid_err * scale_factor))
                weights.append(weight)

    # 3. Get errors from n_ellipses study (tertiary factor - less impact)
    lower_n, upper_n, n_weight = _find_nearest_values(n_observations, STUDIED_N_ELLIPSES)
    for studied_n, weight in [(int(lower_n), 1 - n_weight), (int(upper_n), n_weight)]:
        if weight > 0:
            key = _get_config_key_for_n(studied_n)
            if key in study_data:
                peak_err, peak_std, centroid_err = _extract_optimal_errors(study_data[key])
                # Scale by mean_semi_minor ratio (n study used mean=100)
                scale_factor = mean_semi_minor / 100.0
                errors.append((peak_err * scale_factor, peak_std * scale_factor, centroid_err * scale_factor))
                weights.append(weight * 0.5)  # Lower weight for n_ellipses

    if not errors:
        # Fallback: no matching data
        return (1500.0 * mean_semi_minor / 100.0, 500.0 * mean_semi_minor / 100.0, 1200.0 * mean_semi_minor / 100.0)

    # Weighted average
    total_weight = sum(weights)
    peak_err = sum(e[0] * w for e, w in zip(errors, weights)) / total_weight
    peak_std = sum(e[1] * w for e, w in zip(errors, weights)) / total_weight
    centroid_err = sum(e[2] * w for e, w in zip(errors, weights)) / total_weight

    # Increase std if parameters are outside studied ranges (extrapolation uncertainty)
    extrapolation_factor = 1.0
    if mean_semi_minor < STUDIED_MEAN_SEMI_MINOR[0] or mean_semi_minor > STUDIED_MEAN_SEMI_MINOR[-1]:
        extrapolation_factor *= 1.5
    if cv < STUDIED_CV[0] or cv > STUDIED_CV[-1]:
        extrapolation_factor *= 1.3
    if n_observations < STUDIED_N_ELLIPSES[0] or n_observations > STUDIED_N_ELLIPSES[-1]:
        extrapolation_factor *= 1.2

    peak_std *= extrapolation_factor

    return (peak_err, peak_std, centroid_err)


def estimate_error(n_observations: int, semi_minor_mean_m: float, semi_minor_cv: float, cell_size_m: float) -> ErrorEstimate:
    """
    Estimate expected error for density peak location.

    Uses interpolation from correlation study empirical data to predict
    the expected distance between the computed density peak and the true
    center of the underlying distribution.

    Args:
        n_observations: Number of ellipses in the dataset
        semi_minor_mean_m: Mean semi-minor axis in meters
        semi_minor_cv: Coefficient of variation of semi_minor (std/mean)
        cell_size_m: Grid cell size in meters

    Returns:
        ErrorEstimate with expected error bounds and confidence intervals
    """
    # Load study data
    try:
        study_data = load_correlation_study_data()
    except FileNotFoundError:
        # Return conservative estimate if study data unavailable
        default_error = semi_minor_mean_m * 15.0  # ~15x mean_semi_minor is conservative
        return ErrorEstimate(
            expected_peak_error_m=default_error,
            peak_error_std_m=default_error * 0.5,
            expected_centroid_error_m=default_error * 0.8,
            centroid_error_std_m=default_error * 0.4,
            confidence_interval_95_m=(default_error * 0.3, default_error * 2.5),
            factors={"n_observations": n_observations, "semi_minor_mean_m": semi_minor_mean_m, "semi_minor_cv": semi_minor_cv, "study_data_available": False},
            low_confidence=True,
            warning_message="Correlation study data not found. Using conservative estimates.",
        )

    # Interpolate from study data
    peak_error, peak_std, centroid_error = _interpolate_errors(study_data, semi_minor_mean_m, semi_minor_cv, n_observations)

    # Estimate centroid std as ~80% of peak std (typically more stable)
    centroid_std = peak_std * 0.8

    # Compute 95% confidence interval (assuming roughly normal distribution)
    ci_low = max(0, peak_error - 1.96 * peak_std)
    ci_high = peak_error + 1.96 * peak_std

    # Check if error exceeds cell size (low confidence warning)
    low_confidence = peak_error > cell_size_m
    warning_message = None
    if low_confidence:
        warning_message = (f"Estimated peak error ({peak_error:.0f}m) exceeds cell size ({cell_size_m:.0f}m). "
                          f"Density peak location may not be reliable. Consider using more observations or smaller ellipses.")

    return ErrorEstimate(
        expected_peak_error_m=round(peak_error, 1),
        peak_error_std_m=round(peak_std, 1),
        expected_centroid_error_m=round(centroid_error, 1),
        centroid_error_std_m=round(centroid_std, 1),
        confidence_interval_95_m=(round(ci_low, 1), round(ci_high, 1)),
        factors={"n_observations": n_observations, "semi_minor_mean_m": round(semi_minor_mean_m, 1), "semi_minor_cv": round(semi_minor_cv, 3), "cell_size_m": round(cell_size_m, 1)},
        low_confidence=low_confidence,
        warning_message=warning_message,
    )

def resample_grid(source: np.ndarray, target_shape: tuple[int, int]) -> np.ndarray:
    """
    Resample source grid to match target shape using bilinear interpolation.

    This allows comparing grids of different sizes by resampling one to match the other.
    """
    if source.shape == target_shape:
        return source

    zoom_factors = (target_shape[0] / source.shape[0], target_shape[1] / source.shape[1])
    return ndimage.zoom(source, zoom_factors, order=1)  # order=1 = bilinear


def normalize_grid(grid: np.ndarray) -> np.ndarray:
    """Normalize grid to 0-1 range for comparison."""
    max_val = grid.max()
    if max_val > 0:
        return grid / max_val
    return grid


def compare_grids_different_sizes(
    reference: np.ndarray,
    candidate: np.ndarray,
    hotspot_percentile: float = 95.0,
) -> dict:
    """
    Compare two grids that may have different sizes.

    Resamples the candidate to match reference size for direct comparison.
    Also computes statistics at original resolutions.
    """
    # Resample candidate to match reference
    candidate_resampled = resample_grid(candidate, reference.shape)

    # Normalize both for comparison
    ref_norm = normalize_grid(reference)
    cand_norm = normalize_grid(candidate_resampled)

    # Basic statistics
    diff = ref_norm - cand_norm
    rmse = float(np.sqrt(np.mean(diff ** 2)))

    # Correlation (flatten for pearsonr)
    from scipy import stats
    ref_flat = ref_norm.ravel()
    cand_flat = cand_norm.ravel()

    if np.std(ref_flat) > 0 and np.std(cand_flat) > 0:
        pearson_r, _ = stats.pearsonr(ref_flat, cand_flat)
    else:
        pearson_r = 1.0 if np.allclose(ref_flat, cand_flat) else 0.0

    # Hotspot overlap (Jaccard)
    ref_threshold = np.percentile(ref_norm, hotspot_percentile)
    cand_threshold = np.percentile(cand_norm, hotspot_percentile)

    ref_hotspots = ref_norm >= ref_threshold
    cand_hotspots = cand_norm >= cand_threshold

    intersection = np.sum(ref_hotspots & cand_hotspots)
    union = np.sum(ref_hotspots | cand_hotspots)
    jaccard = float(intersection / union) if union > 0 else 1.0

    # Peak location comparison
    ref_peak = np.unravel_index(np.argmax(ref_norm), ref_norm.shape)
    cand_peak = np.unravel_index(np.argmax(cand_norm), cand_norm.shape)

    # Convert peak to relative position (0-1)
    ref_peak_rel = (ref_peak[0] / ref_norm.shape[0], ref_peak[1] / ref_norm.shape[1])
    cand_peak_rel = (cand_peak[0] / cand_norm.shape[0], cand_peak[1] / cand_norm.shape[1])

    peak_distance = np.sqrt(
        (ref_peak_rel[0] - cand_peak_rel[0]) ** 2 +
        (ref_peak_rel[1] - cand_peak_rel[1]) ** 2
    )

    return {
        "rmse_normalized": rmse,
        "pearson_r": pearson_r,
        "hotspot_jaccard": jaccard,
        "peak_distance_relative": peak_distance,
        "reference_shape": reference.shape,
        "candidate_shape": candidate.shape,
        "reference_max": float(reference.max()),
        "candidate_max": float(candidate.max()),
        "reference_nonzero": int(np.count_nonzero(reference)),
        "candidate_nonzero": int(np.count_nonzero(candidate)),
    }

class TestWeightComputation:

        """Verify weight = (duration / n_obs) / reference_rate."""
        n = 5
        base_time = datetime(2024, 1, 1, 12, 0, 0)

        # 5 observations over 1 hour (3600 seconds)
        lats = np.full(n, 40.0)
        lons = np.full(n, -74.0)

        timestamps = np.array([
            base_time + timedelta(seconds=i * 900) for i in range(n)  # 15 min apart

            semi_minor=np.full(n, 25.0),
            azimuth=np.full(n, 0.0),

            timestamps=timestamps,
        )

        config = DwellConfig(min_observations=3, min_dwell_time_sec=300, max_dwell_radius_m=100, reference_rate_sec=60.0)
        result = detect_dwells(obs, config)

        assert len(result.dwells) == 1
        dwell = result.dwells[0]

def compute_probability_mass(sigma: float) -> float:
    """
    Calculate theoretical probability mass captured within sigma standard deviations
    for a 2D Gaussian distribution.

    For a 2D Gaussian, the CDF at radius r is: 1 - exp(-r^2 / 2)
    where r is the Mahalanobis distance (number of standard deviations).
    """
    return 1.0 - np.exp(-sigma ** 2 / 2.0)


def measure_memory_usage(func, *args, **kwargs):
    """
    Measure peak memory usage of a function call using tracemalloc.

    Returns:
        tuple: (result, peak_memory_mb)
    """
    tracemalloc.start()
    try:
        result = func(*args, **kwargs)
        current, peak = tracemalloc.get_traced_memory()
        peak_mb = peak / (1024 * 1024)
    finally:
        tracemalloc.stop()
    return result, peak_mb

def resample_grid(source: np.ndarray, target_shape: tuple[int, int]) -> np.ndarray:
    """Resample source grid to match target shape using bilinear interpolation."""
    if source.shape == target_shape:
        return source
    zoom_factors = (target_shape[0] / source.shape[0], target_shape[1] / source.shape[1])
    return ndimage.zoom(source, zoom_factors, order=1)


def normalize_grid(grid: np.ndarray) -> np.ndarray:
    """Normalize grid to 0-1 range for comparison."""
    max_val = grid.max()
    if max_val > 0:
        return grid / max_val
    return grid


def compare_grids_different_sizes(reference: np.ndarray, candidate: np.ndarray, hotspot_percentile: float = 95.0) -> dict:
    """
    Compare two grids that may have different sizes.

    Resamples the candidate to match reference size for direct comparison.
    """
    # Resample candidate to match reference
    candidate_resampled = resample_grid(candidate, reference.shape)

    # Normalize both for comparison
    ref_norm = normalize_grid(reference)
    cand_norm = normalize_grid(candidate_resampled)

    # Basic statistics
    diff = ref_norm - cand_norm
    rmse = float(np.sqrt(np.mean(diff ** 2)))

    # Correlation
    ref_flat = ref_norm.ravel()
    cand_flat = cand_norm.ravel()

    if np.std(ref_flat) > 0 and np.std(cand_flat) > 0:
        pearson_r, _ = stats.pearsonr(ref_flat, cand_flat)
    else:
        pearson_r = 1.0 if np.allclose(ref_flat, cand_flat) else 0.0

    # Hotspot overlap (Jaccard)
    ref_threshold = np.percentile(ref_norm, hotspot_percentile)
    cand_threshold = np.percentile(cand_norm, hotspot_percentile)

    ref_hotspots = ref_norm >= ref_threshold
    cand_hotspots = cand_norm >= cand_threshold

    intersection = np.sum(ref_hotspots & cand_hotspots)
    union = np.sum(ref_hotspots | cand_hotspots)
    jaccard = float(intersection / union) if union > 0 else 1.0

    # Peak location comparison
    ref_peak = np.unravel_index(np.argmax(ref_norm), ref_norm.shape)
    cand_peak = np.unravel_index(np.argmax(cand_norm), cand_norm.shape)

    # Convert peak to relative position (0-1)
    ref_peak_rel = (ref_peak[0] / ref_norm.shape[0], ref_peak[1] / ref_norm.shape[1])
    cand_peak_rel = (cand_peak[0] / cand_norm.shape[0], cand_peak[1] / cand_norm.shape[1])

    peak_distance = np.sqrt((ref_peak_rel[0] - cand_peak_rel[0]) ** 2 + (ref_peak_rel[1] - cand_peak_rel[1]) ** 2)

    return {
        "rmse_normalized": rmse,
        "pearson_r": float(pearson_r),
        "hotspot_jaccard": jaccard,
        "peak_distance_relative": float(peak_distance),
        "reference_shape": reference.shape,
        "candidate_shape": candidate.shape,
        "reference_max": float(reference.max()),
        "candidate_max": float(candidate.max()),
        "reference_sum": float(reference.sum()),
        "candidate_sum": float(candidate.sum()),
    }

    print(f"\nOutput files saved to: {OUTPUT_DIR}/")
    print(f"Benchmark results saved to: {json_path}")

    return results

        function getDensityColor(density, minDensity, maxDensity) {
            if (maxDensity === minDensity) return '#ff0000';

            // Ensure at least 2 orders of magnitude for meaningful log scale (matches PNG behavior)
            let effectiveMin = minDensity;
            if (maxDensity / minDensity < 100) {
                effectiveMin = maxDensity / 100;
            }

            // Log scale for better visualization
            const logMin = Math.log10(Math.max(effectiveMin, 1e-10));
            const logMax = Math.log10(Math.max(maxDensity, 1e-10));
            const logVal = Math.log10(Math.max(density, 1e-10));
            const t = Math.max(0, Math.min(1, (logVal - logMin) / (logMax - logMin)));

            // 'hot' colormap: black -> red -> yellow -> white
            const colors = [
                [10, 0, 0],       // near black
                [128, 0, 0],      // dark red
                [255, 0, 0],      // red
                [255, 128, 0],    // orange
                [255, 255, 0],    // yellow
                [255, 255, 128],  // light yellow
                [255, 255, 255]   // white
            ];
            const idx = t * (colors.length - 1);
            const i = Math.floor(idx);
            const f = idx - i;
            const c1 = colors[Math.min(i, colors.length - 1)];
            const c2 = colors[Math.min(i + 1, colors.length - 1)];
            const r = Math.round(c1[0] + f * (c2[0] - c1[0]));
            const g = Math.round(c1[1] + f * (c2[1] - c1[1]));
            const b = Math.round(c1[2] + f * (c2[2] - c1[2]));
            return `rgb(${r},${g},${b})`;
        }
